CEH v13 Module 4: Enumeration — Free Practice Questions with Explanations

Question 1: SNMP enumeration with the default community strings 'public' and 'private' is commonly performed with:

Answer: C — snmpwalk/snmpget traverse the MIB tree; unchanged default communities let attackers pull system info, interfaces, and routing tables.

Question 2: The default ports used by LDAP are:

Answer: C — LDAP listens on 389, LDAPS on 636. Port 161/162 is SNMP; 137/138 is NetBIOS; 25/110 are SMTP/POP3.

Question 3: NetBIOS names (computer names, usernames, workgroups) can be enumerated via which service port?

Answer: A — NetBIOS uses ports 137 (Name Service), 138 (Datagram), and 139 (Session); tools like nbtscan, enum4linux, and rpcclient abuse these to enumerate Windows hosts.

Question 4: Which SMTP commands can be abused to verify whether a user account exists?

Answer: B — VRFY asks the server to confirm an address and EXPN expands mailing lists; if left enabled they hand attackers valid usernames (tools: smtp-user-enum, Swaks).

Question 5: The term 'enumeration' refers to:

Answer: C — Enumeration takes scanning one step further by pulling actionable intelligence — accounts, shares, services — that can be targeted in the next attack phase.

Question 6: enum4linux is a tool for enumerating:

Answer: B — enum4linux wraps rpcclient, smbclient, and nmblookup to enumerate Windows/Active Directory hosts over SMB and NetBIOS.

Question 7: A successful SNMP walk using the default 'public' community can reveal:

Answer: C — 'public' is read-only, so it leaks system details (uptime, hostname, interfaces, routes) — a rich passive-recon goldmine, but not passwords or email.

Question 8: The ldapsearch utility is used to enumerate:

Answer: B — ldapsearch issues LDAP queries against directory servers (e.g., Active Directory over LDAP) to extract user lists and group memberships.

Question 9: Compared to scanning, enumeration differs because it:

Answer: B — Scanning tells you what's listening; enumeration interrogates those services to learn usernames, shares, versions, and structure.

Question 10: Swaks is a tool used to:

Answer: B — Swaks (Swiss Army Knife for SMTP) sends custom SMTP commands — handy for VRFY/EXPN enumeration and mail-server misconfiguration testing.
