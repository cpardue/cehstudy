CEH v13 Module 2: Footprinting & Reconnaissance — Free Practice Questions with Explanations

Last updated August 2026 · 10 questions · Module 2 of 20

Passive and active reconnaissance: OSINT tools, DNS/WHOIS interrogation, document metadata, and mapping the target attack surface. Below are 10 original multiple-choice practice questions for this module, each with a detailed explanation. They follow the style and difficulty of the EC-Council Certified Ethical Hacker v13 exam (312-50).

Question 1: Passive footprinting is defined as:

Answer: A — Passive techniques include search engines, social media, public records, and WHOIS lookups — nothing touches the target directly, so detection risk is minimal.

Question 2: Which of the following is an example of ACTIVE footprinting?

Answer: A — A zone transfer query goes directly to the target's DNS servers, making it active — and more likely to be detected — unlike purely passive OSINT sources.

Question 3: Which command queries a domain's Mail Exchange (MX) records?

Answer: D — 'dig target.com MX' returns the mail servers for the domain. A-records map hostnames to IPv4, WHOIS covers registration data.

Question 4: Which tool aggregates email addresses and subdomains from hundreds of public sources including search engines, SSL certificates, and virtual hosts?

Answer: C — theHarvester (e.g., theHarvester -d target.com) pulls emails, subdomains, and hostnames from 200+ public sources — a core OSINT recon tool.

Question 5: FOCA is best described as a tool for:

Answer: A — FOCA (Find Out Come Access) extracts author names, company info, timestamps, tracked changes, and network paths from Office and PDF document metadata.

Question 6: Maltego is primarily used for:

Answer: D — Maltego builds visual graphs of relationships (people ↔ domains ↔ IPs ↔ companies) to map an organization's attack surface.

Question 7: An attacker can obtain a complete list of all hosts in a domain's DNS database via:

Answer: C — Zone transfers replicate the full DNS zone; if misconfigured and allowed to any client, 'dig axfr' exposes every hostname — a classic footprinting win.

Question 8: In 'thin' WHOIS systems, the registry database:

Answer: D — Thin WHOIS keeps minimal records centrally and defers full details to registrar servers; thick WHOIS stores complete data in one searchable database.

Question 9: Which Regional Internet Registry (RIR) serves the Americas?

Answer: A — ARIN covers the Americas; AFRINIC Africa; APNIC Asia-Pacific; RIPE NCC Europe/Middle East; LACNIC Latin America and the Caribbean.

Question 10: Shodan is best described as:

Answer: A — Shodan indexes banners, services, and devices on the internet — used to discover IoT/SCADA gear, open ports, and misconfigurations at scale (like Censys and ZoomEye).
