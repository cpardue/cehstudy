CEH v13 Module 18: Lateral Movement — Free Practice Questions with Explanations

Question 1: Lateral movement is:

Answer: B — After initial access, attackers pivot host-to-host (reusing stolen credentials) to reach domain controllers, file servers, and crown-jewel data.

Question 2: A Pass-the-Hash (PtH) attack authenticates using:

Answer: C — Many SMB logins accept the hash itself — so a dumped NTLM value is as good as the password for authenticating elsewhere.

Question 3: Pass-the-Ticket differs from Pass-the-Hash because it replays:

Answer: A — Extraction from memory (Mimikatz sekurlsa::tickets) yields valid TGTs/TGSs that authenticate to services until they expire.

Question 4: Mimikatz's primary role in lateral movement is:

Answer: C — It reads LSASS process memory for NTLM/NTLMv2 hashes, Kerberos tickets, and plaintext — the fuel for PtH/PtT attacks.

Question 5: 'Pivoting' refers to:

Answer: B — The foothold becomes a proxy (SSH tunnels, SOCKS, Proxifier) — reaching segmented networks the attacker can't scan from outside.

Question 6: PSExec and RDP (port 3389) are commonly abused for lateral movement because they:

Answer: A — With valid (stolen) admin credentials, both give full control of another host — so audit remote-logon behavior and restrict admin paths.

Question 7: SMB (port 445) is a key lateral-movement channel because it:

Answer: C — Named pipes over SMB power PsExec, wmic remote execution, and admin$ share copies — a primary PtH/relay target.

Question 8: A Golden Ticket attack grants the attacker:

Answer: C — Because KDCs trust tickets signed with the KRBTGT key, a forged TGT is valid until that hash is reset — rotate KRBTGT after such incidents.

Question 9: A primary defense against lateral movement is:

Answer: B — If each host is a locked room (JEA, tiered admin model) and jumps between rooms are alerted, movement stalls quickly.

Question 10: Credential dumping on a Windows host often targets memory because:

Answer: B — Modern Windows protects disk copies of secrets — so attackers read LSASS memory instead, driving defenses like Credential Guard and LSA protection.
