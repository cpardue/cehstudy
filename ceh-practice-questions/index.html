Footprinting and Reconnaissance

Question 1: Which of the following is the MOST passive method of gathering information about a target organization?

Answer: B — Searching public websites and social media is purely passive because no direct interaction with the target's systems occurs.

Question 2: Which command would you use to query a domain's DNS records using the DIG tool?

Answer: C — The DIG command with "target.com MX" queries Mail Exchange records for the domain.

Question 3: What type of footprinting tool harvests email addresses, subdomains, and IP addresses from over 200 free sources?

Answer: A — TheHarvester specifically aggregates data from 200+ free sources including search engines, SSL certificates, and web crawlers.

Scanning Vulnerabilities

Question 4: In a TCP SYN stealth scan (-sS in Nmap), what does the target port send back in response to a SYN packet from the scanner?

Answer: B — In a SYN scan, an open port responds with SYN-ACK, while a closed port responds with RST.

Question 5: Which Nmap scan type sends FIN packets without any flags set to detect how a target port responds?

Answer: D — The FIN scan (-sF) sends TCP packets with only the FIN flag set.

Question 6: What does an Nmap OS detection (-O) flag primarily analyze to identify the target operating system?

Answer: C — OS detection works by analyzing TCP/IP stack fingerprinting characteristics.

System Hacking

Question 7: Which technique involves adding malicious code to a legitimate program or system binary to maintain persistent access?

Answer: B — Binary patching modifies the code of legitimate binaries to include backdoors.

Question 8: What is the PRIMARY purpose of a rootkit on a compromised system?

Answer: A — Rootkits conceal the presence of malware, backdoors, and unauthorized processes.

Question 9: Which password attack tries common passwords against a single user account before moving to the next user?

Answer: C — Password spraying uses a single common password against many user accounts to avoid lockouts.

Malware

Question 10: What type of malware encrypts the victim's files and demands payment for the decryption key?

Answer: B — Ransomware encrypts files and demands payment (often in cryptocurrency).

Question 11: Which malware analysis technique involves running the malicious program in an isolated environment while observing its behavior?

Answer: D — Dynamic analysis runs malware in a sandboxed environment to observe its actual behavior.

Social Engineering

Question 12: An attacker calls an employee pretending to be from IT support, asking for their password. What type of attack is this?

Answer: A — Vishing is voice-based phishing conducted over the phone.

Question 13: What is the term for a pretext where an attacker creates a fabricated scenario to manipulate a target?

Answer: C — Pretexting involves creating an elaborate false story/scenario.

Web Application Attacks

Question 14: Which SQL injection technique determines if a vulnerability exists by sending a TRUE or FALSE condition?

Answer: B — Boolean-based blind SQL injection sends TRUE/FALSE conditions and infers data from differences in page responses.

Question 15: What type of XSS attack stores the malicious script on the target server's database?

Answer: A — Stored XSS persists on the server and affects all visitors.
