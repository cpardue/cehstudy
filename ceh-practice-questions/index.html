Footprinting and Reconnaissance

Question 1: Which of the following is the MOST passive method of gathering information about a target organization?

Answer: B — Searching public websites and social media is purely passive because no direct interaction with the target's systems occurs. Options A, C, and D all involve active engagement with the target's infrastructure or personnel.

Question 2: Which command would you use to query a domain's DNS records using the DIG tool?

Answer: C — The DIG command with "target.com MX" queries Mail Exchange records for the domain. Option A uses incorrect syntax (should be "dig target.com any"), B is NSLOOKUP not DIG, and D queries WHOIS database not DNS records.

Question 3: What type of footprinting tool harvests email addresses, subdomains, and IP addresses from over 200 free sources including search engines, web caches, and databases?

Answer: A — TheHarvester specifically aggregates data from 200+ free sources including search engines, SSL certificates, virtual hosts, and web crawlers. Maltego uses visual link analysis, Shodan is an IoT search engine, and GHDB searches Google's index.

Scanning Vulnerabilities

Question 4: In a TCP SYN stealth scan (-sS in Nmap), what does the target port send back in response to a SYN packet from the scanner?

Answer: B — In a SYN scan, an open port responds with SYN-ACK (the scanner then sends RST to tear down the connection), while a closed port responds with RST. This is why it's called "stealth" — the full TCP handshake is never completed.

Question 5: Which Nmap scan type sends FIN packets without any flags set to detect how a target port responds?

Answer: D — The FIN scan (-sF) sends TCP packets with only the FIN flag set. According to RFC 793, closed ports should respond with RST, while open ports ignore the packet (no response). This can bypass some firewall rules.

Question 6: What does an Nmap OS detection (-O) flag primarily analyze to identify the target operating system?

Answer: C — OS detection works by analyzing TCP/IP stack fingerprinting characteristics including ICMP response types, TCP Initial Sequence Number (ISN) generation, TCP window size, and other low-level protocol behaviors unique to each OS.

System Hacking

Question 7: Which technique involves adding malicious code to a legitimate program or system binary to maintain persistent access?

Answer: B — Binary patching modifies the code of legitimate binaries to include backdoors. Rootkits hide the existence of malicious processes, password spraying is a credential attack, and DNS tunneling is a data exfiltration method.

Question 8: What is the PRIMARY purpose of a rootkit on a compromised system?

Answer: A — Rootkits are specifically designed to conceal the presence of malware, backdoors, and unauthorized processes by hooking system calls and hiding files/processes/network connections from standard detection tools.

Question 9: Which password attack tries common passwords against a single user account before moving to the next user?

Answer: C — Password spraying uses a single common password (like "Password123!") against many user accounts. This avoids account lockouts that would occur with a dictionary attack against a single account.

Malware

Question 10: What type of malware encrypts the victim's files and demands payment for the decryption key?

Answer: B — Ransomware encrypts files on the victim's system and demands payment (often in cryptocurrency) for the decryption key. Popular variants include LockBit, REvil, and BlackCat.

Question 11: Which malware analysis technique involves running the malicious program in an isolated environment while observing its behavior?

Answer: D — Dynamic analysis runs malware in a sandboxed/isolated environment to observe its actual behavior (file changes, network connections, registry modifications). Static analysis examines code without executing it.

Social Engineering

Question 12: An attacker calls an employee pretending to be from IT support, asking for their password to "verify their identity." What type of social engineering attack is this?

Answer: A — Vishing is voice-based phishing conducted over the phone. Regular phishing uses email, smishing uses SMS/text messages, and tailgating is a physical security attack where someone follows an authorized person into a restricted area.

Question 13: What is the term for a pretext where an attacker creates a fabricated scenario to manipulate a target into divulging information?

Answer: C — Pretexting involves creating an elaborate false story/scenario (e.g., pretending to be from HR, IT, or a vendor). Baiting offers something tempting (free USB drive), quid pro quo offers a service in exchange for info, and pharming redirects DNS to malicious sites.

Web Application Attacks

Question 14: Which SQL injection technique determines if a vulnerability exists by sending a TRUE or FALSE condition and observing different responses?

Answer: B — Boolean-based blind SQL injection sends TRUE/FALSE conditions (e.g., "OR 1=1") and infers data from differences in page responses. Time-based uses delays (SLEEP()), union-based combines results with UNION SELECT, and error-based forces database errors to reveal data.

Question 15: What type of XSS attack stores the malicious script on the target server's database and executes it when other users view the affected page?

Answer: A — Stored XSS persists on the server (e.g., in a comment field or user profile) and affects all visitors. Reflected XSS requires the victim to click a malicious link. DOM-based XSS manipulates the browser-side JavaScript without server interaction.
