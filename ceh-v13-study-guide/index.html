What Is the CEH Certification?

The Certified Ethical Hacker (CEH) certification is offered by EC-Council and is one of the most recognized ethical hacking certifications globally.

CEH v13 is the latest version of the exam, updated to reflect modern threat landscapes including cloud security, IoT/OT hacking, and advanced lateral movement techniques. The exam code is 312-50.

Who Should Get CEH Certified?

  • Security Analysts / Engineers
  • IT Administrators
  • SOC Analysts
  • Penetration Testers
  • Security Consultants
  • Students

CEH Exam Details

  • Exam Code: 312-50
  • Format: Multiple choice, 125 questions
  • Duration: 4 hours
  • Passing Score: 60% (75 out of 125)
  • Cost: $1,199 USD (exam voucher); $849 for EC-Council students
  • Prerequisites: 2 years of IT security experience OR EC-Council training certification
  • Delivery: Pearson VUE test centers or online proctoring

How to Study for the CEH Exam

Step 1: Understand the Exam Blueprint

Before diving into study materials, review the official EC-Council exam objectives. Know exactly which topics will be tested and their weight percentages.

Step 2: Build Foundational Knowledge

Start with Module 1: Introduction to Ethical Hacking to understand the legal and ethical framework.

Step 3: Use Our Free Flashcards

  • Selective studying: Focus on one or multiple modules at a time
  • Randomized order: No repeats per session to test true knowledge
  • Mobile-friendly: Study on any device, anywhere
  • Completely free: No signup required

Step 4: Practice with Hands-On Labs

  • Virtual lab environments (TryHackMe, HackTheBox)
  • Practice penetration testing in isolated networks
  • Command-line tool practice (Nmap, Metasploit, Wireshark)
  • Web application vulnerability labs (OWASP WebGoat, DVWA)

Step 5: Review and Reinforce

  • Review all flashcard modules at least twice
  • Focus on weak areas identified during practice tests
  • Re-read key definitions and cryptographic concepts
  • Practice timeline estimation for scanning phases

Don't rush through Modules 02 and 03 — they form the foundation for the entire ethical hacking methodology. Spend extra time on footprinting, scanning tools, and port numbers.

CEH Study Tips from Experienced Test Takers

  1. Memorize port numbers — Common ports (21, 22, 23, 25, 53, 80, 443, 445, 3389)
  2. Understand scan types — Know the difference between TCP connect, SYN stealth, FIN, XMAS, and NULL scans
  3. Learn tool flags — Nmap switches (-sS, -sV, -O, -A), Metasploit modules, Wireshark filters
  4. Cryptography basics — Symmetric vs asymmetric algorithms, hash functions, digital signatures, PKI
  5. Think like an attacker — CEH tests offensive mindset
  6. Eliminate wrong answers — Multiple choice questions often have 2 obviously wrong options
  7. Watch for keywords — "BEST", "FIRST", "MOST appropriate" change the correct answer

Resources and Tools You Should Know

Reconnaissance & Scanning

  • Nmap — Network discovery and port scanning
  • Masscan — High-speed internet scanner
  • TheHarvester — Email/subdomain harvesting
  • Maltego — Link analysis and OSINT
  • Shodan — Internet-connected device search engine

Vulnerability Analysis

  • Nessus — Vulnerability scanner
  • OpenVAS — Open-source vulnerability scanner
  • Qualys — Cloud-based vulnerability management

Exploitation

  • Metasploit Framework — Exploitation framework
  • Burp Suite — Web application testing
  • SQLmap — SQL injection automation
  • John the Ripper — Password cracking

Post-Exploitation & Reporting

  • Mimikatz — Credential extraction from Windows
  • Netcat / Ncat — Network utility
  • Wireshark — Packet analysis
  • Aircrack-ng — Wireless network assessment

Frequently Asked Questions

How long does it take to prepare for the CEH exam?

Most candidates spend 4–8 weeks preparing, studying 10–15 hours per week.

Is CEH v13 harder than v12?

v13 introduces new topics like IoT/OT hacking, cloud security, and lateral movement.

Can I pass CEH with just flashcards?

Flashcards are excellent for memorizing key terms but not sufficient alone. Combine them with hands-on labs.

How much does the CEH exam cost?

The standalone exam voucher costs $1,199 USD. EC-Council students pay $849.
