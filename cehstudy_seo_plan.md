## GitHub Pages Constraints

- Static HTML/CSS/JS only — no server-side rendering (SSR)
- No backend/serverless functions
- Client-side JS apps (flashcards) work but are NOT SEO-crawlable
- Google Analytics (client-side) is supported
- Custom domain, HTTPS, robots.txt, sitemap.xml all supported

## URL Structure Rules

**Good:**
```
/ceh-v13/
/ceh-v13/module-01/
/ceh-v13-study-guide/
/ceh-practice-questions/
/glossary/sql-injection/

```

```
/content/abc123
/study?module=4&card=31
```

## Implementation Notes

1. **All SEO content must be static HTML** — not generated by JavaScript
2. **Flashcard app is the product, not the SEO vehicle** — it stays as-is but gets surrounded by crawlable content
3. **Each page needs exactly one H1** — no duplicate or missing H1s
4. **Canonical URLs on every page** — self-referencing for indexable pages
5. **Last reviewed date on all certification content** — freshness matters for exam prep
6. **EC-Council disclaimer must be prominent** — legal protection

---

## Priority Order

1. **Phase 0** (backup) — do first

3. **Phase 4** (infrastructure) — robots.txt, sitemap before indexing
4. **Phase 3** (support pages) — E-E-A-T signals
5. **Phase 2** (module pages) — long-tail keyword opportunities
6. **Phase 5** (content expansion) — authority building
