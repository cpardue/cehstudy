Module 13: Web Application Attacks

Section 1: Web Application Architecture

Web applications run on web servers and are accessed through web browsers. Three main components:

  • Client Layer: Browser that renders HTML/CSS/JavaScript
  • Application Layer: Web server processing requests (Apache, Nginx, IIS)
  • Data Layer: Database servers storing application data (MySQL, PostgreSQL, MongoDB)

Common Web Technologies

  • Frontend: HTML, CSS, JavaScript, React, Angular, Vue.js
  • Backend: PHP, Python (Django/Flask), Java (Spring), Node.js, Ruby on Rails
  • Databases: MySQL, PostgreSQL, MongoDB, Oracle, MSSQL
  • Web Servers: Apache HTTP Server, Nginx, Microsoft IIS

Section 3: SQL Injection (SQLi)

SQL Injection = injecting malicious SQL code into input fields to manipulate the backend database.

SQLi Types

  • In-band SQLi (Classic): Same channel for attack and results. Union-based and Error-based.
  • Blind SQLi: Attacker infers data through application responses. Boolean-based and Time-based.
  • Out-of-band SQLi: Uses different channel (DNS, HTTP requests) to extract data

SQLi Attack Examples

# Authentication bypass
' OR 1=1 --
admin' --
# Union-based data extraction
1 UNION SELECT username, password FROM users --
# Stacking queries
1; DROP TABLE users --

SQLi Tools: sqlmap, Burp Suite, OWASP ZAP

Section 4: Cross-Site Scripting (XSS)

XSS = injecting malicious scripts into web pages viewed by other users.

XSS Types

  • Reflected XSS: Malicious script reflected from web server. Requires user interaction.
  • Stored XSS (Persistent): Script permanently stored on target server. Most dangerous.
  • DOM-based XSS: Vulnerability in client-side JavaScript code.

XSS Impact: Session hijacking, Keylogging, Defacement, Redirection, Phishing

Section 5: Other Web Application Attacks

Server-Side Request Forgery (SSRF)

Attacker exploits server to make HTTP requests to internal resources. Bypasses firewall rules.

Cross-Site Request Forgery (CSRF)

Tricks authenticated user into submitting unintended requests. Exploits automatic cookie sending.

XML External Entity (XXE)

Attacker injects malicious XML entities to read files, perform SSRF, or cause DoS.

Web Server Vulnerabilities

  • Directory Traversal: ../ to access files outside web root
  • Local File Inclusion (LFI): Include local files via user input
  • Remote File Inclusion (RFI): Include remote files for code execution
  • SSTI: Server-Side Template Injection

Section 6: Web Application Countermeasures

Input Validation

  • Whitelist validation: Only allow expected input patterns
  • Parameterized queries/prepared statements: Separate SQL code from data
  • Output encoding: HTML-encode special characters to prevent XSS
  • CSP (Content Security Policy): Restrict sources of executable scripts

Authentication and Session Security

  • Anti-CSRF tokens: Unique token per session
  • HttpOnly cookie flag: Prevent JavaScript access to cookies
  • Secure cookie flag: Only send cookies over HTTPS
  • SameSite cookie attribute: Prevent cross-site cookie sending

Web Application Firewall (WAF)

Filters and monitors web traffic. Types: Network-based, Host-based, Cloud-based.

Section 7: Web Application Testing Tools

Scanner Tools: Burp Suite, OWASP ZAP, Nikto, Acunetix

Manual Testing Tools: Browser DevTools, cURL, Postman

Section 8: Notable Web Application Attacks

Target Data Breach (2013)

SQL injection via third-party HVAC company. 40 million credit cards stolen.

Yahoo Email Breach (2014)

SQL injection and XSS compromised all 3 billion Yahoo accounts.

SolarWinds Orion Supply Chain Attack (2020)

SUNBURST backdoor in software updates. Compromised US government agencies.

Log4Shell (CVE-2021-44228)

Critical RCE in Log4j logging library. Affected millions of systems worldwide.
