Free 6-Week CEH v13 Study Plan — Structured Exam Preparation

This structured 6-week study plan covers all 20 CEH v13 exam domains with a balanced pace that works for both self-study candidates and those supplementing an EC-Council training course. The plan assumes 2 hours per day (weekdays) plus additional weekend time, for a total of approximately 15-20 hours per week.

Week-by-Week Breakdown

Week 1: Foundation & Reconnaissance
Modules 1-3 | ~12 hours total
  • Module 1: Introduction to Ethical Hacking — CIA triad, hacker types, rules of engagement, penetration testing methodology
  • Module 2: Footprinting & Reconnaissance — WHOIS, DNS enumeration, OSINT, social footprinting, network reconnaissance
  • Module 3: Scanning Networks — Nmap scan types (SYN, FIN, XMAS, NULL), port scanning, vulnerability scanners, banner grabbing
📌 Weekly Milestone: Complete all Module 1-3 flashcards (200+ cards). Run a Nmap SYN scan against a test VM. Identify at least 5 open ports and their services.
Week 2: Network Security & Enumeration
Modules 4-6 | ~12 hours total
  • Module 4: Enumeration — SMB, SNMP, LDAP, DNS enumeration techniques, user/group discovery
  • Module 5: Vulnerability Analysis — CVE, CVSS scoring, Nessus/OpenVAS scanning, vulnerability assessment methodology
  • Module 6: System Hacking — Password cracking (Hydra, John the Ripper), privilege escalation, buffer overflows, exploit development
📌 Weekly Milestone: Complete all Module 4-6 flashcards. Practice cracking a password with Hydra against a Metasploitable VM. Understand CVSS v3 scoring for at least 5 real CVEs.
Week 3: Attack Vectors & Malware
Modules 7-10 | ~12 hours total
  • Module 7: Malware Threats — Trojan, worm, virus, ransomware, rootkit, APT, botnet lifecycle and detection
  • Module 8: Sniffing & Traffic Analysis — Wireshark filters, ARP spoofing, packet analysis, network monitoring, IDS/IPS basics
  • Module 9: Social Engineering — Phishing, vishing, pretexting, tailgating, baiting, BEC, psychological manipulation
  • Module 10: Denial of Service — SYN flood, UDP flood, amplification attacks, DDoS mitigation, rate limiting
📌 Weekly Milestone: Complete all Module 7-10 flashcards. Capture and analyze at least 50 packets in Wireshark. Identify a TCP three-way handshake and one ARP request/reply.
Week 4: Web & Application Attacks
Modules 11-15 | ~12 hours total
  • Module 11: Session Hijacking — TCP sequence prediction, cookie theft, session management, encryption of sessions
  • Module 12: Evading IDS/Firewalls — Packet fragmentation, protocol manipulation, port scanning evasion, honeypot detection
  • Module 13: Hacking Web Servers — Apache/IIS vulnerabilities, directory traversal, command injection, file inclusion
  • Module 14: Hacking Web Applications — OWASP Top 10, XSS (reflected/stored/DOM), CSRF, insecure deserialization
  • Module 15: SQL Injection — Union-based, boolean blind, time-based blind, error-based SQLi, WAF bypass
📌 Weekly Milestone: Complete all Module 11-15 flashcards. Use Burp Suite to identify and exploit one XSS vulnerability and one SQL injection on DVWA (Damn Vulnerable Web App).
Week 5: Modern Security Domains
Modules 16-20 | ~12 hours total
  • Module 16: Wireless Networks — WEP/WPA/WPA2/WPA3, evil twin attacks, Aircrack-ng, wireless penetration testing
  • Module 17: Mobile Platforms — Android exploitation, iOS jailbreaking, mobile malware, MDM security, app reverse engineering
  • Module 18: IoT & OT Hacking — SCADA/ICS protocols, PLC vulnerabilities, industrial control system attacks, firmware analysis
  • Module 19: Cloud Computing — AWS/Azure/GCP security, cloud misconfiguration, serverless security, container security
  • Module 20: Cryptography — AES, RSA, hashing (SHA-256, MD5), PKI, certificate attacks, post-quantum crypto
📌 Weekly Milestone: Complete all Module 16-20 flashcards. Set up a home Wi-Fi network and capture WPA handshake (for educational purposes). Review PKI certificate chain in browser.
Week 6: Mock Exams & Final Review
All modules | ~15 hours total (increased intensity)
  • Day 1-2: Review all weak areas identified by progress tracker. Re-study any modules with below 80% recall rate.
  • Day 3-4: Take two full timed mock exams (4 hours each, 125 questions). Use our practice questions or find additional exam simulations.
  • Day 5: Review all incorrect answers from mock exams. Revisit specific concepts that were missed.
  • Day 6: Final flashcard sweep — go through ALL 20 module card sets one final time (fast speed, focus on remaining gaps).
  • Day 7: Light review only. Review shortcut notes (ports, scan types, crypto algorithms). Rest and prepare for exam day.
📌 Weekly Milestone: Score 80%+ on at least one mock exam. Be comfortable with all high-frequency topics (ports, Nmap flags, SQLi types, XSS types, crypto algorithms). If below 75%, consider delaying exam by 1-2 weeks.

Study Tips for Maximum Retention

  • Spaced repetition: Use the CEHStudy flashcard app which automatically reshuffles — don't try to memorize order
  • Active recall: Cover the answer and force yourself to recall before flipping. Don't just re-read.
  • Teach-back method: Explain each concept out loud as if teaching someone else. Gaps in explanation = gaps in knowledge.
  • Lab integration: Theory without practice fades. At least 30 minutes of hands-on tool practice per day is non-negotiable.
  • Sleep and rest: Memory consolidation happens during sleep. Avoid cramming sessions past midnight.

Frequently Asked Questions About CEH Exam Preparation

Q: Is 6 weeks enough time to pass the CEH exam?
A: Yes, for candidates with some security background. Complete beginners may need 8-10 weeks. The key is consistency — 2 hours daily beats 10 hours on Sunday.

Q: How many practice questions should I do before the exam?
A: Aim for at least 500-1,000 practice questions across all domains before your exam date. Focus on understanding WHY you got an answer wrong, not just memorizing correct answers.

Q: Should I watch videos or read books instead of using flashcards?
A: Use multiple methods for best retention. Flashcards are great for active recall and spaced repetition. Combine with video content (for visual learners) and hands-on labs (for practical understanding).

Q: What if I don't finish all modules in 6 weeks?
A: Prioritize the highest-weighted domains: Scanning & Vulnerability Assessment (20%), Footprinting & Reconnaissance (15%), and Exploiting System Services (15%). These three areas alone account for 50% of exam questions.
