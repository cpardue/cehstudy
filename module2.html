Module 2: Footprinting & Reconnaissance

Footprinting and reconnaissance is the process of gathering as much information as possible about an organization before initiating cyber attacks.

Section 1: Footprinting Fundamentals

What is Footprinting?

The process of collecting information about a remote organization on external systems and networks before the actual hacking begins. Also known as information gathering.

Purpose

  • Discover potential attack vectors
  • Identify security weaknesses
  • Understand the target's infrastructure

Section 2: Passive vs Active Reconnaissance

Passive Reconnaissance

Gathering information without directly interacting with the target system. Harder to detect.

  • Searching public databases and websites
  • Using Google for OSINT
  • Checking DNS records publicly
  • Social media research

Active Reconnaissance

Interacting directly with the target system. Easier to detect.

  • Ping sweeps and port scanning
  • Network mapping
  • Whois lookups against the target
  • Vulnerability scanning

Section 3: OSINT Tools & Sources

OSINT (Open Source Intelligence)

Intelligence gathered from publicly available sources that can be used to identify potential targets and attack vectors.

OSINT Sources

  • Search engines (Google, Bing, DuckDuckGo)
  • Social media platforms
  • Public registries (domain WHOIS)
  • Government databases
  • Company websites and press releases
  • Job postings (reveal technology stack)

OSINT Tools

  • Google Dorking: Advanced Google search operators
  • TheHarvester: Emails, subdomains, hosts
  • Shodan: Internet-connected device search
  • Censys: Search engine for internet-hosted objects
  • Maltego: Data mining and graph visualization

Section 4: DNS Reconnaissance

DNS Record Types

  • A: IPv4 address
  • AAAA: IPv6 address
  • MX: Mail exchange server
  • NS: Name server
  • CNAME: Canonical name (alias)
  • TXT: Text records (SPF, DKIM)
  • SOA: Start of authority
  • CAA: Certificate Authority Authorization

DNS Enumeration Techniques

  • DNS zone transfer (AXFR)
  • Reverse DNS lookups
  • Finding subdomains
