CEH v13 Exam Domains & Blueprint — Complete Domain Breakdown

Last updated August 2026 · All 20 domains with question weightings

The EC-Council Certified Ethical Hacker v13 (CEH v13) exam is a 125-question multiple choice test administered over 4 hours. Understanding the domain weightings below helps you prioritize study time and focus on the topics that will appear most frequently on your exam.

Exam Overview

Complete Domain Breakdown with Weightings

Module 1: Introduction to Ethical Hacking
~5% of exam | ~6 questions
  • CIA triad (Confidentiality, Integrity, Availability)
  • Hacker types: white hat, black hat, grey hat, script kiddie
  • Penetration testing methodology and rules of engagement
  • Legal/ethical framework for security testing
Module 2: Footprinting & Reconnaissance
~15% of exam | ~19 questions
  • WHOIS lookup and passive/active information gathering
  • DNS enumeration (AXFR, reverse DNS, subdomain discovery)
  • OSINT techniques and social media footprinting
  • Network footprinting: subnet scanning, IP range identification
  • Search engine dorks and specialized OSINT tools
💡 High-yield: Know the difference between passive vs active footprinting. Be able to identify information gathering techniques and their noise levels.
Module 3: Scanning Networks
~15% of exam | ~19 questions
  • Nmap scan types: SYN (-sS), UDP (-sU), FIN (-sF), XMAS (-sX), NULL (-sN)
  • Port scanning techniques and common port numbers (21, 22, 23, 25, 53, 80, 443, 445, 3389)
  • Vulnerability scanners: Nessus, OpenVAS, Qualys
  • Banner grabbing and service version detection (-sV)
  • OS fingerprinting and network topology mapping
💡 High-yield: Memorize all Nmap scan flags and what packets they send. Know which ports map to which services.
Module 4: Enumeration
~5% of exam | ~6 questions
  • SMB/Samba enumeration (enum4linux, smbclient)
  • SNMP enumeration (snmpwalk, snmpget, community strings)
  • LDAP directory service enumeration
  • NetBIOS and WINS enumeration
Module 5: Vulnerability Analysis
~10% of exam | ~13 questions
  • CVE (Common Vulnerabilities and Exposures) identifiers
  • CVSS scoring system (v3.1): Base, Temporal, Environmental scores
  • Vulnerability assessment methodology and reporting
  • Exploit vs vulnerability vs threat definitions
  • Patch management and vulnerability lifecycle
Module 6: System Hacking
~10% of exam | ~13 questions
  • Password cracking: brute force, dictionary, rainbow table, credential stuffing
  • Privilege escalation: local (user → root) and remote
  • Buffer overflow attacks: stack-based, heap-based
  • Metasploit framework and exploit development basics
  • Account manipulation and system backdoors
💡 High-yield: Know the difference between local and remote privilege escalation. Understand how each password cracking method works.
Module 7: Malware Threats
~5% of exam | ~6 questions
  • Malware types: virus, worm, trojan, rootkit, ransomware, spyware
  • APT (Advanced Persistent Threat) lifecycle and indicators
  • Botnets and C&C communication
  • Polymorphic and metamorphic malware
  • Malware analysis and detection techniques
Module 8: Sniffing & Traffic Analysis
~5% of exam | ~6 questions
  • Wireshark and tcpdump packet analysis
  • ARP spoofing/poisoning attacks
  • Man-in-the-middle attack vectors
  • Network monitoring and IDS/IPS basics
  • TCP/IP packet structure and headers
Module 9: Social Engineering
~10% of exam | ~13 questions
  • Phishing types: spear phishing, whaling, smishing, vishing
  • Pretexting, baiting, quid pro quo techniques
  • Physical social engineering: tailgating, piggybacking, badge cloning
  • Business Email Compromise (BEC)
  • Psychological manipulation: urgency, authority, reciprocity
Module 10: Denial of Service
~5% of exam | ~6 questions
  • DoS vs DDoS: single source vs distributed
  • SYN flood, UDP flood, ICMP flood attacks
  • Application layer DoS (HTTP flood, Slowloris)
  • Amplification attacks (DNS, NTP, memcached)
  • Mitigation: rate limiting, SYN cookies, load balancing
Module 11: Session Hijacking
~5% of exam | ~6 questions
  • TCP sequence number prediction attacks
  • Cookie theft and session fixation
  • Session management best practices
  • Protection: HTTPS, secure cookies, session timeouts
Module 12: Evading IDS, Firewalls & Honeypots
~5% of exam | ~6 questions
  • Packet fragmentation and splitting to evade detection
  • Protocol manipulation and tunneling
  • Port scanning evasion techniques
  • Honeypot identification and detection
  • Firewall bypass methods
Module 13: Hacking Web Servers
~5% of exam | ~6 questions
  • Apache and IIS common vulnerabilities
  • Directory traversal (../ attacks)
  • Command injection and file inclusion (LFI/RFI)
  • Web server misconfiguration
Module 14: Hacking Web Applications
~5% of exam | ~6 questions
  • OWASP Top 10 vulnerabilities
  • Cross-Site Scripting (XSS): reflected, stored, DOM-based
  • Cross-Site Request Forgery (CSRF)
  • Insecure deserialization and authentication failures
Module 15: SQL Injection
~5% of exam | ~6 questions
  • Union-based SQL injection
  • Boolean-based blind SQL injection
  • Time-based blind SQL injection
  • Error-based SQL injection
  • WAF bypass and parameterized queries as prevention
💡 High-yield: Know the difference between all SQLi types and how to identify each from application behavior.
Module 16: Hacking Wireless Networks
~5% of exam | ~6 questions
  • WEP vs WPA vs WPA2 vs WPA3 security differences
  • Aircrack-ng and wireless attack tools
  • Evil twin attacks and rogue access points
  • Rogue AP detection and wireless site surveys
  • 802.1X authentication and EAP methods
Module 17: Hacking Mobile Platforms
~5% of exam | ~6 questions
  • Android exploitation and APK analysis
  • iOS security and jailbreaking concepts
  • Mobile malware types and distribution
  • MDM (Mobile Device Management) security
  • Bluetooth, NFC, and proximity attacks
Module 18: IoT & OT Hacking
~5% of exam | ~6 questions
  • SCADA and ICS protocols (Modbus, DNP3, OPC)
  • PLC vulnerabilities and industrial network security
  • IoT device security weaknesses and firmware analysis
  • OT/IT convergence security challenges
Module 19: Cloud Computing Security
~5% of exam | ~6 questions
  • IaaS, PaaS, SaaS security models and shared responsibility
  • AWS, Azure, GCP common misconfigurations
  • Cloud-native security tools and monitoring
  • API security in cloud environments
Module 20: Cryptography & Physical Security
~10% of exam | ~13 questions
  • Symmetric: AES, DES, 3DES, RC4
  • Asymmetric: RSA, Diffie-Hellman, ECC
  • Hashing: SHA-256, SHA-512, MD5 (broken), bcrypt
  • PKI: certificates, CAs, revocation (CRL, OCSP)
  • Cryptographic attacks: man-in-the-middle, rainbow table, brute force
  • Post-quantum cryptography basics
💡 High-yield: Know key lengths for each algorithm. Understand which hashing algorithms are considered broken (MD5, SHA-1) and why.

Frequently Asked Questions

Q: Are the domain percentages exact or approximate?
A: They are approximate. EC-Council does not publish exact question counts per domain. These percentages are based on the CEH v13 exam blueprint and community-reported data from test-takers. Individual exams may vary slightly.

Q: Can I skip low-weighted domains during my study?
A: No. Even a 5% domain represents ~6 questions, which is more than the difference between passing (75) and failing (74). Cover all domains but spend proportionally more time on high-weighted ones.

Q: Does the CEH v13 exam have scenario-based questions?
A: Yes. Many questions present a scenario and ask you to identify the appropriate action, tool, or technique. Practice reading questions carefully and eliminating obviously wrong answers first.
