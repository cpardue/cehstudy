Module 12: Virus and Trojan Attacks

Section 1: Malware Fundamentals

Malware (Malicious Software) = any program created to cause damage to a computer, server, client, or computer network.

Malware Lifecycle

  1. Injection: Malware enters the system (email attachment, download, USB drive)
  2. Installation: Malware installs itself on the target
  3. Execution: Malware is activated and begins its malicious activity
  4. Delivery: Malware delivers its payload (data theft, encryption, backdoor)

Types of Malware

  • Virus: Attaches itself to a program or file and requires human action to spread
  • Worm: Self-replicating malware that spreads without human interaction
  • Trojan: Disguises as legitimate software, creates backdoor
  • Ransomware: Encrypts files and demands payment for decryption
  • Spyware: Secretly monitors user activity and collects information
  • Rootkit: Hides presence of malware from detection tools
  • Bot/Botnet: Compromised system controlled by attacker as part of network
  • Logic Bomb: Triggers malicious action when specific condition is met

Section 2: Virus Types and Techniques

Virus Characteristics

A virus requires a host program or file to attach to. It needs human action (running the infected program) to propagate.

Virus Lifecycle

  1. Linking: Virus code is linked to host program
  2. Waiting (Dormant): Virus waits for trigger condition
  3. Execution: Host program runs, activating the virus
  4. Testing/Discovery: Virus tests for target to infect
  5. Infection/Replication: Virus infects other files/systems
  6. Execution: Virus payload is carried out
  7. Modification: Virus may modify itself to avoid detection

Virus Types

  • Boot Sector Virus: Infects the Master Boot Record (MBR) or boot sector. Loads into memory when computer starts.
  • File-Infector Virus: Attaches to executable files (.exe, .com). Activates when infected program runs.
  • Macro Virus: Embedded in macro commands within documents (Word, Excel). Spreads through document sharing.
  • Polymorphic Virus: Changes its code (using mutation engine) each time it replicates to avoid signature-based detection.
  • Metamorphic Virus: Rewrites its entire code while maintaining functionality. More advanced than polymorphic.
  • Multipartite Virus: Combines boot sector and file-infector techniques. Infects both files and boot sectors.
  • Resident Virus: Installs itself in system memory, allowing it to infect files as they are opened or created.
  • Non-Resident Virus: Does not install in memory. Activates when infected file is run, infects other files, then exits.
  • Overwrite Virus: Overwrites programs and data with its own code, destroying the original file.

Virus Protection Techniques

  • Signature-based detection: Matches malware against known signatures (limited effectiveness against polymorphic viruses)
  • Heuristic analysis: Detects suspicious behavior or code patterns rather than specific signatures
  • Scanning: Examines entire files or system areas for known virus patterns

Section 3: Trojan Types and Techniques

Trojan (Trojan Horse) = malware that disguises itself as legitimate software. Unlike viruses, Trojans do not replicate themselves.

Trojan Characteristics

  • Does not self-replicate
  • Relies on social engineering to trick users into installation
  • Creates backdoor for remote access
  • Can install additional malware

Trojan Types

TypeDescription
Remote Access Trojan (RAT)Provides attacker full remote control of infected system
Banker TrojanSteals financial information (online banking credentials)
Downloader TrojanDownloads and installs additional malware
Dropper TrojanDelivers and deploys other malware to target system
Game Plug-in TrojanHides inside game add-ons to steal information
GamotrojanMiners cryptojacking resources disguised as games
Ransomware TrojanDelivers ransomware payload (e.g., CryptoLocker)
Wiper TrojanDestructively erases data from target systems

Reverse Connection Trojan

Trojan initiates outbound connection to attacker's command and control server, bypassing inbound firewall rules.

  1. Victim installs the Trojan (disguised as legitimate software)
  2. Trojan opens a backdoor on the victim system
  3. Trojan connects to attacker's C2 server (often on port 80 or 443)
  4. Attacker gains remote access to the compromised system

Section 4: Other Malware Types

Ransomware

Encrypts victim's files and demands payment (usually cryptocurrency) for the decryption key.

Types

  • Cryptographic ransomware: Encrypts files with strong algorithms (AES, RSA)
  • Locker ransomware: Locks user out of system without encrypting files

Ransomware Distribution

  • Email attachments (malicious documents with macros)
  • Drive-by downloads from compromised websites
  • Remote Desktop Protocol (RDP) brute force attacks
  • Exploit kits targeting vulnerabilities
  • Bundled with other malware (Trojan downloaders)

Spyware and Keyloggers

Spyware secretly monitors user activity. Keyloggers record keystrokes to capture passwords and sensitive data.

Rootkits

Tools that hide the existence of malware from detection methods. Operate at various levels of the system.

Rootkit Types

  • User-Mode Rootkits: Hook API calls to hide processes, files, registry keys
  • Kernel-Mode Rootkits: Operate at ring 0 level, most dangerous and hardest to detect
  • Hypervisor Rootkits: Run below the operating system, control the entire system
  • Boot Sector Rootkits: Infect MBR, load before OS
  • Firmware Rootkits: Infected BIOS/UEFI, persist across reboots and reinstalls

Rootkit Techniques

  • System call hooking: Intercept and modify API calls to hide malicious activity
  • Inline hooking (MS Hook): Modify first few bytes of functions to redirect execution
  • IDT hooking: Interrupt Descriptor Table modification
  • SSDT hooking: System Service Descriptor Table modification

Logic Bombs

Malicious code that triggers when specific conditions are met (date, event, action). Often planted by disgruntled employees.

Fileless Malware

Operates entirely in memory without writing to disk. Uses legitimate system tools (PowerShell, WMI) to execute malicious code.

Section 5: Trojan Tools and Techniques

Trojan Development Tools

  • Armitage: GUI-based network attack tool with built-in Trojan generation
  • Thc-ipv6: IPv6 attack toolkit that includes Trojan capabilities
  • Metasploit Framework: Generates backdoor payloads (meterpreter)
  • Mimikatz: Extracts credentials and creates pass-the-hash tokens

Trojan Infection Techniques

  1. Disguise: Package malware as legitimate software (cracks, keygens, games)
  2. Obfuscation: Encrypt or encode the payload to avoid detection
  3. Distribution: Deliver via email, website, USB drive, or software bundle
  4. Execution: User runs the Trojan, activating the backdoor
  5. C2 Communication: Trojan connects to attacker's command and control server

Section 6: Malware Countermeasures

Prevention Techniques

  • Antivirus/Antimalware: Install and maintain updated signature databases
  • Firewalls: Block unauthorized outbound connections (detect reverse trojans)
  • Application whitelisting: Only allow approved programs to run
  • Email filtering: Scan attachments and links for malware
  • Regular updates/patching: Fix vulnerabilities that malware exploits
  • User education: Train employees to recognize social engineering
  • Least privilege: Limit user permissions to reduce malware impact

Detection Techniques

  • Behavioral analysis: Monitor for suspicious process behavior
  • Integrity monitoring: Check for unauthorized file/registry changes
  • Network monitoring: Detect C2 communication patterns
  • Endpoint Detection and Response (EDR): Advanced threat detection on endpoints

Rootkit Detection Tools

  • SFC (System File Checker): Windows system file integrity checking
  • GMER: Rootkit detection tool (scan for kernel-level modifications)
  • RKill: Terminates rootkit processes before running antivirus
  • MAL/Rootkit detect: Built-in Windows Defender capabilities
  • chkrootkit: Linux rootkit detection tool

Ransomware Countermeasures

  • Regular backups: Maintain offline backups of critical data
  • Email hygiene: Filter malicious attachments
  • Application control: Restrict execution of untrusted code
  • Disable macros: Prevent Office document macros from running
  • Network segmentation: Limit ransomware spread

Section 7: Notable Malware Incidents

Melissa (1999)

Macro virus that spread via Outlook email attachments. Requested $400 for "password protected" files, distributed itself through email contacts.

ILOVEYOU (2000)

Email worm that spread via subject "ILOVEYOU" with attached "LOVE-LETTER-FOR-YOU.TXT.vbs". Caused an estimated $10 billion in damages worldwide.

Stuxnet (2010)

Sophisticated worm targeting Iranian nuclear facilities. Used multiple zero-day exploits and four stolen digital certificates to spread via USB drives.

CryptoLocker (2013)

Ransomware that encrypted files and demanded Bitcoin payment. Distributed via Gameover ZeuS trojan. Estimated $3 million in ransom before takedown.

WannaCry (2017)

Ransomware worm that exploited EternalBlue (Windows SMB vulnerability). Spread rapidly across 150 countries, affecting 200,000+ computers including NHS hospitals in the UK.

Emotet (2014-2021)

Initially a banking trojan, evolved into a modular malware distribution platform. Delivered TrickBot and ransomware payloads through email campaigns.
