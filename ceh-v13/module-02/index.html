CEH v13 Module 2: Information Security Footprinting

Footprinting is the first phase of ethical hacking — gathering publicly available information about a target organization. This module covers footprinting vs reconnaissance, DNS enumeration, WHOIS lookups, Google hacking (OSINT), email footprinting, network footprinting, and website footprinting techniques.

Key Topics Covered

  • Footprinting vs Reconnaissance: understanding the distinction
  • DNS enumeration: zone transfers, DNS records (A, MX, NS, CNAME, TXT, SOA)
  • WHOIS lookups and domain registration information
  • Google hacking: advanced search operators for OSINT
  • Email footprinting: finding email addresses and formats
  • Network footprinting: IP ranges, ASN discovery
  • Website footprinting: sitemap analysis, robots.txt, directory enumeration

Important Terms & Concepts

Footprinting: The process of gathering information about a target organization's systems, domain names, and infrastructure from public sources. Also called information gathering.
Reconnaissance: A broader term that includes footprinting plus active probing of the target's systems. Footprinting is passive; reconnaissance can be both passive and active.
DNS Zone Transfer (AXFR): Requesting a complete copy of a DNS zone file from a nameserver. Can expose all domain hosts and IPs. Often misconfigured — a critical information leak.
Google Hacking: Using advanced Google search operators (site:, intext:, filetype:, etc.) to find sensitive information exposed by poorly configured websites.

How to Study This Module

  • Know the difference between footprinting and reconnaissance
  • Memorize DNS record types and their purposes
  • Practice Google hacking with advanced search operators

Frequently Asked Questions

What is the difference between footprinting and reconnaissance?
Footprinting is passive information gathering from public sources. Reconnaissance includes active probing of the target's systems to identify vulnerabilities.

What is Google Hacking?
Using advanced Google search operators to find sensitive information that organizations have accidentally exposed — configuration files, databases, admin panels, and more.
