CEH v13 Module 2: Footprinting & Reconnaissance

This module covers footprinting and reconnaissance techniques — the first phase of any ethical hacking engagement. Learn passive vs active information gathering, OSINT tools, DNS enumeration, WHOIS lookups, email harvesting, Google Dorks, and other intelligence-gathering methods.

Key Topics Covered

  • Passive vs active reconnaissance techniques
  • OSINT (Open Source Intelligence) tools and methodologies
  • DNS enumeration: zone transfers, NS/MX/A records
  • WHOIS lookup and reverse IP lookups
  • Email harvesting and social engineering preparation
  • Google Dorks: advanced search operators for security research
  • Network mapping and website footprinting
  • Corporate intelligence gathering via public records

Important Terms & Concepts

Footprinting: The process of collecting information about a target organization's systems and services. It is the first step in the intelligence-driven penetration testing framework.
Passive Reconnaissance: Gathering information without directly interacting with the target system (e.g., Google searches, WHOIS lookups, social media research). Lower risk of detection.
Active Reconnaissance: Directly interacting with target systems to gather information (e.g., ping sweeps, port scanning, DNS zone transfers). Higher risk of detection but more detailed.
OSINT: Open Source Intelligence — collecting data from publicly available sources including websites, social media, government databases, and search engines.
DNS Zone Transfer (AXFR): A mechanism to replicate DNS records across name servers. Misconfigured zone transfers can expose entire network topology.
Google Dorks: Advanced Google search operators used to find sensitive information exposed on the web, e.g., site:example.com filetype:pdf

OSINT Tools

  • Maltego: Visual link analysis for reconnaissance
  • TheHarvester: Email, subdomain, and name harvesting
  • Shodan/Censys: Internet-connected device search engines
  • Google Advanced Search: Site-specific searches with operators
  • WHOIS/DNS tools: Domain registration and DNS record lookups

How to Study This Module

  • Understand the differences between passive and active reconnaissance
  • Memorize common OSINT tools and their specific uses
  • Learn Google Dork operators: site:, filetype:, inurl:, intitle:, etc.
  • Understand DNS record types and their relevance to footprinting
