CEH v13 Module 2: Footprinting & Reconnaissance

This module covers footprinting and reconnaissance techniques — the foundational information gathering phase of ethical hacking. Topics include DNS record analysis, WHOIS lookups, Google hacking, Shodan exploration, email footprinting, network footprinting, and website footprinting methods.

Key Topics Covered

  • DNS record types: A, AAAA, CNAME, MX, NS, TXT, SOA, PTR, SRV, CAA
  • WHOIS lookups and domain registration data
  • Google hacking with advanced search operators
  • Shodan for IoT and service discovery
  • Email footprinting: Hunter.io, theHarvester, Maltego
  • Network footprinting: traceroute, ping sweeps, banner grabbing
  • Website footprinting: sitemap analysis, robots.txt, technology fingerprinting

Important Terms & Concepts

DNS Zone Transfer (AXFR): Requesting a full copy of the DNS zone file. Can expose all internal hostnames. Defenses: restrict to authorized secondary DNS servers, disable AXFR.
Google Hacking: Using advanced Google search operators (site:, inurl:, intitle:, filetype:, etc.) to discover sensitive information exposed on the web. Tools: GHDB, Google Dorks.
Shodan: Search engine for internet-connected devices. Reveals open ports, services, banners, and vulnerabilities. Used for reconnaissance and vulnerability assessment.
theHarvester: Open-source OSINT tool that gathers emails, subdomains, hosts, employee names, and open port information from public sources (search engines, PGP key servers, virtual hosts).

How to Study This Module

  • Memorize all DNS record types and their purposes
  • Practice using Google hacking operators in a safe environment
  • Understand how Shodan works and what information it reveals
  • Know the difference between passive and active reconnaissance

Frequently Asked Questions

What is the difference between footprinting and reconnaissance?
Footprinting is broader — it encompasses all information gathering about an organization. Reconnaissance is more focused on technical data collection from discovered targets.

Which Google hacking operator is most useful?
site: (specific domains), filetype: (documents), inurl: (URL patterns), intitle: (page titles). Combine multiple operators for precision.
