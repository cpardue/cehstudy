CEH v13 Module 12: Evading IDS, Firewalls & Honeypots

This module covers techniques for evading security controls including IDS, firewalls, and honeypots. Topics include IDS types (network-based, host-based), firewall evasion methods, tunneling, fragmentation, and honeypot/honeynet detection.

Key Topics Covered

  • IDS types: NIDS vs HIDS, signature vs anomaly-based
  • Firewall evasion: IP fragmentation, tunneling, decoy scanning
  • Tunneling techniques: DNS, ICMP, HTTP/HTTPS
  • Honeypot/honeynet detection and avoidance
  • Encrypted traffic evasion

Important Terms & Concepts

NIDS: Network-based IDS monitors all network traffic. Placed at network perimeter. Signature-based (known patterns) vs anomaly-based (baseline deviations). Tools: Snort, Suricata.
HIDS: Host-based IDS monitors a single system. Checks file integrity, logs, processes. Detects post-compromise activity. Tools: OSSEC, Tripwire.

How to Study This Module

  • Know IDS types and their differences
  • Understand firewall evasion techniques
  • Learn tunneling methods and their uses

Frequently Asked Questions

What's the best IDS evasion technique?
Tunneling through allowed ports (DNS/HTTPS) — most firewalls permit this traffic.
