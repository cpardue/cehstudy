CEH v13 Module 4: Enumeration

Enumeration extracts user accounts, passwords, hash values, file shares, and system information from target systems. This module covers SNMP, LDAP, SMB, DNS zone transfers, and WinRM enumeration techniques used by ethical hackers.

Key Topics Covered

  • SNMP enumeration: community strings, MIBs, SNMPwalk
  • LDAP enumeration: user accounts, group policies, domain info
  • SMB enumeration: file shares, user lists, password policies
  • DNS zone transfers: AXFR, IXFR protocols
  • WinRM and PowerShell remoting enumeration
  • NetBIOS and WMI enumeration

Important Terms & Concepts

SNMP Enumeration: Using default/well-known community strings (public/private) to query network devices. Tools: snmpwalk, onesixtyone for brute-forcing community strings.
LDAP Enumeration: Querying Active Directory for users, groups, and policies. Tools: ldapsearch, BloodHound, SharpHound.

How to Study This Module

  • Know each enumeration protocol and what data it reveals
  • Understand common tools for each enumeration type

Frequently Asked Questions

What is the most valuable enumeration target?
Active Directory via LDAP — reveals entire domain hierarchy, user relationships, and group policies in one query.
