CEH v13 Module 4: Enumeration

This module covers enumeration techniques — extracting detailed information from target services. Topics include SNMP enumeration, SMB shares and user listing, LDAP queries, DNS zone transfer, SMTP user enumeration, and Telnet/SSH attacks.

Key Topics Covered

  • SNMP enumeration: community strings, MIB traversal, SNMPwalk
  • SMB enumeration: shares, users, groups, OS info
  • LDAP queries: directory information, user accounts, group membership
  • DNS zone transfer: AXFR, IXFR protocols
  • SMTP enumeration: VRFY, EXPN, RCPT TO commands
  • Telnet and SSH attacks: brute force, banner grabbing

Important Terms & Concepts

SNMP Community Strings: SNMPv1/v2c use plaintext community strings (public/private by default). Tools: snmp-check, BGSU SNMP Scanner, onesixtyone for auditing.
SMB Enumeration: Can reveal shared drives, user accounts, password policies. Tools: smbclient, nmap scripts (smb-enum-shares, smb-enum-users), enum4linux.
DNS Zone Transfer (AXFR): Requesting full DNS zone file from a nameserver. Often succeeds when misconfigured. Tools: nslookup, dig axfr, nmap --dns-strip.
LDAP Queries: Can extract user accounts, groups, computers, password policies. Default ports: 389 (unencrypted), 636 (LDAPS). Tools: ldapsearch, BloodHound.

How to Study This Module

  • Know which protocols/ports are used for each enumeration technique
  • Understand the difference between SNMPv1/v2c vs v3 security
  • Learn common commands for each enumeration tool
  • Understand how to defend against enumeration attacks

Frequently Asked Questions

Which enumeration protocol is most dangerous?
SNMP with default community strings — it can reveal entire network topology, routing tables, and interface statistics. Always change default strings.

What's the best tool for SMB enumeration?
enum4linux combines multiple techniques: smbclient, nmblookup, RPC client, and more into a single comprehensive tool.
