CEH v13 Module 18: Mobile Attacks

This module covers mobile device attacks. Topics include Android/iOS vulnerabilities, mobile malware, SIM cloning, SMS interception, app security, NFC/QR code attacks, and mobile penetration testing.

Key Topics Covered

  • Mobile OS: Android vs iOS — architecture, security models
  • Mobile malware: trojans, spyware, ransomware
  • SIM cloning and SMS interception attacks
  • App security: reverse engineering, code injection
  • NFC/QR code attacks

Important Terms & Concepts

SIM Cloning: Copying SIM card data to another card. Requires physical access or network-based attack. Tools: SIM tool kit, ADB.
Android APK Reverse Engineering: Decompile APK → review source code → find vulnerabilities. Tools: apktool, jadx, dex2jar.

How to Study This Module

  • Know Android vs iOS security differences
  • Understand mobile malware types and delivery methods
  • Learn app reverse engineering techniques

Frequently Asked Questions

Which mobile OS is more secure?
iOS — tighter app store control, sandboxing, slower patch cycle but more consistent enforcement.
