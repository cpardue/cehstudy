CEH v13 Module 8: Sniffing

This module covers network sniffing techniques — capturing and analyzing network traffic. Topics include protocol analysis, packet capture with Wireshark, ARP/DNS/RARP sniffing, switch evasion, and defense mechanisms.

Key Topics Covered

  • Protocol analysis: TCP/IP stack, common protocols
  • Packet capture: Wireshark, tcpdump, Nmap scripts
  • ARP sniffing: intercepting ARP traffic
  • DNS/RARP sniffing techniques
  • Switch evasion: port mirroring, MAC flooding

Important Terms & Concepts

Promiscuous Mode: Network interface configured to capture all traffic on the segment, not just traffic addressed to it. Required for sniffing.
MAC Flooding: Overwhelming switch CAM table with fake MAC addresses forces switch into hub mode, broadcasting all traffic. Defenses: port security, BPDU guard.

How to Study This Module

  • Practice Wireshark capture and filtering
  • Understand common protocol headers
  • Learn switch evasion techniques

Frequently Asked Questions

What is the best tool for sniffing?
Wireshark for analysis, tcpdump for CLI. Both are essential tools.
