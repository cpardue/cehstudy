CEH v13 Module 14: Network Interface Attacks

This module covers attacks targeting network interfaces including wireless, Bluetooth, and mobile devices. Topics include Wi-Fi attacks (WEP/WPA/WPA2 cracking), evil twin, rogue AP, Bluetooth attacks, and mobile device exploitation.

Key Topics Covered

  • Wi-Fi security: WEP, WPA, WPA2, WPA3 protocols and weaknesses
  • Wireless attacks: evil twin, rogue AP, war driving, war chalking
  • Bluetooth attacks: bluejacking, bluesnarfing, Blueborne
  • Mobile device attacks: SIM cloning, SMS interception, app vulnerabilities

Important Terms & Concepts

WEP: Wired Equivalent Privacy — broken protocol using RC4. Vulnerable to IV attacks. Cracked in minutes with aircrack-ng.
Evil Twin: Rogue AP mimicking legitimate network SSID. Users connect unknowingly. Defenses: 802.1X authentication, certificate validation.

How to Study This Module

  • Know wireless security protocol differences (WEP vs WPA vs WPA2 vs WPA3)
  • Understand each attack mechanism
  • Learn defense strategies for wireless networks

Frequently Asked Questions

Which wireless protocol is most secure?
WPA3 — uses AES-256, forward secrecy, SAE authentication. Replaces PSK with more secure handshake.
