CEH v13 Module 6: System Hacking

System hacking involves gaining unauthorized access to target systems and maintaining that access. This module covers password cracking methods, privilege escalation techniques, file system attacks, service exploitation, malware deployment, steganography, and post-exploitation cover-your-tracks activities.

Key Topics Covered

  • Password cracking methods: brute-force, dictionary, rainbow tables, hybrid attacks
  • Privilege escalation techniques: token manipulation, UAC bypass, service exploitation
  • File system attacks: NTFS permissions, alternative data streams (ADS), fileless techniques
  • Service exploitation and backdoor installation
  • Password hashing: LM hashes, NTLM hashes, SAM database
  • Masking access: log clearing, rootkit installation, process hiding
  • Steganography and stegotography techniques
  • Post-exploitation: credential dumping, lateral movement

Important Terms & Concepts

Password Cracking: The process of recovering passwords from encrypted/hashed data using methods like brute-force (trying all combinations), dictionary (common words), rainbow tables (precomputed hashes), and hybrid attacks.
Rainbow Table: A precomputed table of hash values for every possible password combination. Used to reverse cryptographic hash functions quickly — defeated by password salting.
Privilege Escalation: Exploiting a bug or design flaw to gain higher access levels (e.g., standard user → Administrator). Can be vertical (more privileges) or horizontal (same level, different account).
UAC Bypass: Techniques to bypass Windows User Account Control: DLL side-loading, job objects, replace existing process, trusted developer policies.
LM Hash: Legacy Windows password hash — extremely weak, max 14 chars split into two 7-char halves. Easily cracked with tools like John the Ripper.
NTDS.dit: Active Directory database file containing all domain account hashes. Extracted using tools like ntdsutil or volume shadow copy exploitation.
Alternative Data Streams (ADS): NTFS feature allowing hidden data within files. Commonly used by malware for persistence: echo secret > file.txt:hidden.txt
Rootkit: Malicious software designed to hide the existence of other malware by intercepting and modifying OS calls at the kernel level.

How to Study This Module

  • Understand each password cracking method and when to use it (brute-force vs dictionary vs rainbow tables)
  • Memorize privilege escalation techniques, especially UAC bypass methods
  • Know the difference between LM and NTLM hash formats
  • Understand how rootkits hide malicious processes and files at the kernel level

Frequently Asked Questions

What is the most common password attack?
Dictionary attacks are the most commonly used because they balance speed and effectiveness. Most users choose weak, dictionary-based passwords.

How do you prevent privilege escalation?
Apply security patches promptly, disable unnecessary services, configure proper NTFS permissions, enable LSA protection, and restrict administrator privileges.

What is System Hacking in Ethical Hacking?

System Hacking is a critical domain of the Certified Ethical Hacker v13 (CEH v13) exam administered by EC-Council. This module covers the techniques used to gain unauthorized access to target systems, maintain that access through persistence mechanisms, and escalate privileges to maximum control. It encompasses password cracking (brute-force, dictionary, rainbow table attacks), privilege escalation via UAC bypass and token manipulation, Windows file system exploitation including NTFS permissions and alternative data streams, credential dumping from SAM and NTDS.dit, rootkit installation for stealth, and post-exploitation activities like lateral movement and cover-your-tracks. On the CEH v13 exam, questions related to Module 6 account for approximately 10% of total questions.

Key Concepts in System Hacking

  • Password Cracking Methodologies: Brute-force attacks try every possible character combination (2^length for the character set). Dictionary attacks use pre-compiled word lists, making them far faster against weak passwords. Hybrid attacks combine dictionary words with numeric suffixes or leet-speak substitutions. Rainbow tables precompute hash chains to reverse lookups in O(1) time but are defeated by salting — adding random data to each password before hashing. The CEH exam tests when to use each method and how to defend against them.
  • Privilege Escalation & UAC Bypass: Vertical privilege escalation (user → admin) is the primary goal after initial system access. UAC bypass techniques include DLL side-loading (placing a malicious DLL with the same name as a trusted one), Job Object abuse, FOD (Files on Demand) hijacking, and exploiting unquoted service paths. On Windows, the CEH exam emphasizes understanding that UAC is not full protection — it simply requires user consent for elevation, and multiple techniques can bypass or trick this prompt.
  • Credential Dumping & Pass-the-Hash: The SAM database (C:\Windows\System32\config\SAM) stores local account NTLM hashes. The NTDS.dit file on domain controllers stores all domain account hashes. Tools like Mimikatz extract these in memory using lsass.exe process injection. Once hashes are obtained, pass-the-hash attacks allow authentication to other systems without knowing the plaintext password — no password entry required, just the hash. This is a lateral movement technique the CEH exam heavily emphasizes.
  • Rootkits & Process Hiding: Rootkits operate at the kernel level to intercept system calls and hide malicious processes, files, registry keys, and network connections from both the user and security software. User-mode rootkits patch specific functions in memory; kernel-mode rootkits hook the SSDT (System Service Descriptor Table) or use kernel modules. Detection involves comparing in-memory data structures with disk-based ones, using tools like RootkitRevealer or GMER.

Tools Used in System Hacking

Essential system hacking tools for CEH exam preparation include Mimikatz (credential dumping, pass-the-hash, UAC bypass), John the Ripper and Hashcat (offline password cracking with GPU acceleration), Metasploit Framework (exploit development and post-exploitation module execution), Impacket library (Python-based Windows protocol attacks including wmiexec, psexec for lateral movement), and Responder (LLMNR/NBT-NS poisoning to capture NTLMv2 hashes). For privilege escalation specifically, tools like Watermelon (UAC bypass automation) and PowerUp.ps1 (PowerShell privilege escalation scripts) are commonly referenced. Hands-on practice in a Windows domain environment with Metasploitable or a custom Active Directory lab is essential for exam confidence.

How to Study System Hacking for the CEH v13 Exam

To effectively study Module 6 for the Certified Ethical Hacker exam:

  1. Memorize the password cracking attack types and their defenses: brute-force (lockout policies), dictionary (complexity requirements), rainbow table (salting), hybrid (strong complexity + length)
  2. Understand the Windows credential storage chain: SAM → NTLM hash → lsass.exe in memory → Mimikatz extraction → pass-the-hash to other systems
  3. Hands-on exercise: In a VirtualBox Windows 10 VM, enable Local Security Policy settings to allow anonymous SID/Name resolution, extract the SAM database with samdump2, crack NTLM hashes offline with Hashcat, and document the entire process
  4. Review related modules: Module 5 (Vulnerability Analysis) for identifying the vulnerabilities that enable system hacking, and Module 7 (Malware Threats) for how malware payloads are deployed after initial access

Frequently Asked Questions About System Hacking

What is pass-the-hash and why is it significant on the CEH exam?

Pass-the-hash is a lateral movement technique where an attacker uses a stolen NTLM or NTLMv2 hash to authenticate to other systems without ever knowing the plaintext password. The Windows authentication process compares hashes — it never requires the actual password over the network. This means if you have valid admin hashes from one system, you can authenticate to any other system where that account has admin rights. On the CEH exam, pass-the-hash is a high-frequency topic: know how NTLM authentication works (challenge-response), how hashes are stored (SAM, NTDS.dit, lsass memory), and how to detect/prevent it (disable NTLM, enforce SMB signing, monitor for anomalous logon types 3).

How does UAC differ from a full privilege separation model?

UAC (User Account Control) is not a true privilege separation model — it is a prompt-based system that asks for user consent when an application requests elevation to admin. The user's token contains both a filtered (standard user) and elevated (admin) portion, and UAC decides which to use based on the request. This is fundamentally different from a model where processes run as standard user by default and must explicitly request specific elevated operations. On the CEH exam, this distinction matters because UAC can be bypassed through numerous techniques (DLL hijacking, FOD abuse, COM Elevation Moniker) that trick the consent prompt or avoid it entirely. A true privilege separation model would be far more resistant to these bypass techniques.
