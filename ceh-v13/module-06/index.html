CEH v13 Module 6: Malware Attacks

This module covers malware types, delivery mechanisms, and analysis techniques. Topics include trojans, worms, viruses, rootkits, fileless malware, IoT malware, ransomware, and advanced persistent threats.

Key Topics Covered

  • Trojans: service-based, download/inject, multi-vector delivery
  • Worms: self-propagating, network-based spread
  • Viruses: file, boot sector, macro, polymorphic
  • Rootkits: kernel-mode, user-mode, hypervisor-level
  • Fileless malware: PowerShell, WMI, memory-only attacks
  • Ransomware: crypto, locker, double/extortion

Important Terms & Concepts

Rootkit: Stealthy malware that hides its existence and activities. Types: kernel-mode (most dangerous), user-mode, hypervisor-level, firmware/BIOS. Detection: behavior monitoring, memory analysis.
Fileless Malware: Operates entirely in memory without writing to disk. Uses PowerShell, WMI, and LOLBins. Detection requires behavioral analysis and memory forensics.

How to Study This Module

  • Know malware types and their distinguishing characteristics
  • Understand delivery mechanisms and prevention techniques
  • Learn analysis methods: static vs dynamic, sandboxing

Frequently Asked Questions

What's the most dangerous malware type?
Rootkits (especially hypervisor/firmware) — they operate at the lowest system level and are hardest to detect/remove.
