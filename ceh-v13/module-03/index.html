CEH v13 Module 3: Scanning

Scanning builds on footprinting by actively probing target systems. This module covers port scanning with nmap, network mapping, vulnerability scanning with Nessus and OpenVAS, banner grabbing, and techniques for bypassing IDS and firewalls.

Key Topics Covered

  • Port scanning techniques: SYN, connect, UDP, FIN, Xmas, Null, Idle scans
  • nmap flags and options for different scan types
  • Network mapping and topology discovery
  • Vulnerability scanning: Nessus, OpenVAS, Nexpose
  • Banner grabbing and service identification
  • Firewall and IDS evasion techniques

Important Terms & Concepts

nmap SYN Scan (Stealth Scan): Sends SYN packets and analyzes responses. Faster and less likely to be logged than full connect scans. Uses -sS flag in nmap.
TCP Connect Scan: Completes full TCP handshake. More noticeable but requires no special privileges. Uses -sT flag in nmap.
Xmas Scan: Sends packets with FIN, PSH, and URG flags set. Named after Christmas tree lights. Can determine if port is filtered/unfiltered.

How to Study This Module

  • Know each nmap scan type and when to use it
  • Understand vulnerability scanner operation and report interpretation

Frequently Asked Questions

What is the most common scanning technique?
nmap SYN scan (-sS) is most commonly used — fast, relatively stealthy, and widely supported.

How do you bypass an IDS during scanning?
Use slow timing, fragment packets, decoy scans, sleep between probes, and use nmap's evasion flags (-f, --data-length, -D).
