CEH v13 Module 3: Scanning Networks

This module covers network and system scanning — the second phase of ethical hacking. Learn port scanning techniques, TCP/UDP scanning, banner grabbing, SNMP enumeration, firewall bypass methods, and tools like Nmap, Netcat, and Metasploit.

Key Topics Covered

  • Scanning vs footprinting: differences and relationships
  • TCP connections: three-way handshake, SYN, ACK, FIN flags
  • Port scanning techniques: SYN, connect, UDP, XMAS, NULL, FIN, ACK scan
  • Network mapping and topology discovery
  • Banner grabbing and service identification
  • SNMP enumeration and community strings
  • Firewall and IDS evasion techniques
  • Scanning tools: Nmap, Netcat, Metasploit, Masscan

Important Terms & Concepts

Port Scanning: The process of identifying which ports are open on a target system. Common techniques include SYN scan (stealthy), connect scan (full connection), and UDP scan.
SYN Scan (Half-Open): Sends a SYN packet, reads the response, and immediately disconnects without completing the three-way handshake. Faster and less detectable than full connect scans.
XMAS Scan: Sends a TCP packet with FIN, PSH, and URG flags set. Named after how the packet looks like it's decorated for Christmas. Probes ports without completing connection.
NULL Scan: Sends a TCP packet with no flags set. Only works on UNIX-like systems where closed ports respond with RST.
Banner Grabbing: Connecting to an open port and reading the service's response banner to identify the application and version.
SNMP Enumeration: Using Simple Network Management Protocol to extract network information from devices. Common default community strings: "public" (read-only) and "private" (read-write).

TCP Port States

  • Open: Application is listening on this port
  • Closed: Port is reachable but no service is listening
  • Filtered: Firewall or packet filter is blocking the probe
  • Unfiltered: Port accessibility unknown, but firewall rules are not active
  • Open|Filtered: Cannot determine if open or filtered
  • Closed|Filtered: Cannot determine if closed or filtered

Common Port Numbers

  • 21 FTP — File Transfer Protocol
  • 22 SSH — Secure Shell
  • 23 Telnet — Unencrypted remote access
  • 25 SMTP — Simple Mail Transfer Protocol
  • 53 DNS — Domain Name System
  • 80 HTTP — Hypertext Transfer Protocol
  • 110 POP3 — Post Office Protocol
  • 143 IMAP — Internet Message Access Protocol
  • 443 HTTPS — HTTP Secure
  • 445 SMB &mdahl; Server Message Block
