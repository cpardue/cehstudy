CEH v13 Module 10: Attacks on Web Applications

This module covers web application attacks targeting vulnerabilities in code and configuration. Topics include SQL injection, cross-site scripting (XSS), CSRF, HTTP splitting/smuggling, open redirection, and XML injection.

Key Topics Covered

  • SQL Injection (SQLi): UNION, blind, time-based, stacked queries
  • Cross-Site Scripting (XSS): reflected, stored, DOM-based
  • Cross-Site Request Forgery (CSRF): forced actions on authenticated users
  • HTTP splitting/smuggling: CRLF injection and request desync
  • Open redirection attacks
  • XML injection and XXE attacks

Important Terms & Concepts

SQL Injection (SQLi): Injecting malicious SQL into input fields. Types: UNION-based, blind (boolean/time-based), stacked queries. Tools: sqlmap. Defenses: parameterized queries, input validation.
Cross-Site Scripting (XSS): Injecting client-side scripts into web pages. Types: reflected (URL-based), stored (database-persistent), DOM-based. Tools: Burp Suite. Defenses: output encoding, Content Security Policy.

How to Study This Module

  • Understand each attack type and its variants
  • Know the difference between reflected/stored XSS
  • Learn SQL injection techniques and sqlmap usage
  • Understand OWASP Top 10 vulnerabilities

Frequently Asked Questions

Which web attack is most critical?
SQL injection — it can lead to full database compromise, data exfiltration, and administrative access.
