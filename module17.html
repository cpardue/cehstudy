Module 17: IoT and OT

Section 1: IoT Fundamentals

IoT (Internet of Things) = network of physical devices with sensors, software, and connectivity to exchange data.

IoT Components: Sensors/Actuators, Connectivity (Wi-Fi, Bluetooth, Zigbee, Z-Wave, LoRaWAN, NB-IoT, 5G), Data Processing, User Interface

IoT Device Types: Consumer IoT, Industrial IoT (IIoT), Healthcare IoT (IoMT), Smart City IoT

Section 2: OT and SCADA

OT (Operational Technology) = hardware and software for detecting/causing change in physical processes.

Key OT Components: SCADA, PLC (Programmable Logic Controller), DCS (Distributed Control System), HMI, RTU

OT vs IT: IT focuses on data confidentiality; OT focuses on safety and availability. IT lifecycle 3-5 years; OT lifecycle 10-30 years.

Section 3: IoT/OT Security Challenges

  • Limited processing power - cannot run security software
  • Default credentials - hard-coded passwords never changed
  • No update mechanism - devices cannot be patched
  • Insecure communication - unencrypted data transmission
  • Physical exposure - devices accessible to attackers
  • Large attack surface - billions of devices with inconsistent security

Section 4: IoT/OT Attacks

Common IoT Attacks: Botnet Recruitment (Mirai, Mozi), Firmware Manipulation, RFID/NFC Cloning, Bluetooth Attacks, GPS Spoofing

OT/SCADA Attacks: Stuxnet, TRITON/RTLOG, BlackEnergy 3, Colonial Pipeline Ransomware (2021)

Section 5: IoT/OT Security Frameworks

Best Practices: Network segmentation, Strong authentication (MFA), Encryption (TLS/AES), Firmware signing, Vulnerability management, OT-aware IDS/IPS

Frameworks: NIST IoT Cybersecurity Guide, IEC 62443, OWASP IoT Top 10

Section 6: Notable IoT/OT Incidents

Mirai Botnet (2016)

IoT botnet recruited thousands of cameras/routers. Caused Dyn DNS outage DDoS attack.

Stuxnet (2010)

State-sponsored worm targeting Iranian nuclear centrifuges via Siemens PLCs. Used four zero-day exploits.

Colonial Pipeline (2021)

Ransomware attack on OT systems. Paid $4.4M Bitcoin. Caused fuel shortages across Eastern US.
