SQL Injection

SQL Injection (SQLi) is a code injection technique that exploits vulnerabilities in an application's database interface by inserting or "injecting" malicious SQL statements into input fields. When successfully exploited, it can manipulate the database to disclose, alter, or delete data, and in some cases execute administrative commands on the database server.

Types & Variations

  • Union-based SQLi — Appends UNION SELECT to existing queries to retrieve additional data from other tables
  • Boolean/Blind SQLi — Extracts data through true/false responses without visible error messages
  • Time-based Blind SQLi — Uses time delays (e.g., SLEEP() or WAITFOR DELAY) to infer data when no visible response exists
  • Error-based SQLi — Exploits database error messages that reveal schema information
  • Out-of-band SQLi — Exfiltrates data through DNS lookups or HTTP requests from the database server

Common Tools & Techniques

sqlmap Burp Suite Pro Wireshark Nmap (for service detection)

Ethical hackers and security professionals use these tools in authorized penetration tests and red team operations. Unauthorized use is illegal under the Computer Fraud and Abuse Act (CFAA) and equivalent legislation worldwide.

Real-World Examples

Login Bypass: Input ' OR '1'='1' -- in a username field transforms the query to always return true
Data Exfiltration: UNION SELECT username, password FROM users — appends all user credentials to the response
Database Destruction: DROP TABLE users; — executed when input is concatenated directly into a DELETE or UPDATE statement

How SQL Injection Appears on the CEH v13 Exam

SQL Injection is explicitly covered as CEH v13 Module 15 and appears throughout the exam. Questions test knowledge of attack vectors, detection via input validation analysis, prevention strategies (parameterized queries, stored procedures, WAF rules), and the specific behaviors of different SQLi types. Expect at least 5-7 questions directly addressing SQLi concepts.

Prevention & Detection

  • Input Validation: Implement strict allowlist-based input validation on all user-facing parameters
  • Principle of Least Privilege: Run applications with minimum required permissions
  • Regular Patching: Maintain timely vulnerability management and patch deployment
  • Network Segmentation: Limit lateral movement through zone-based network architecture
  • Monitoring & Alerting: Deploy SIEM/SOAR solutions with threat detection rules for anomalous activity
