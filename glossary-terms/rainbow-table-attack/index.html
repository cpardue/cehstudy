Rainbow Table Attack

A Rainbow Table Attack is a password cracking technique that uses precomputed tables of hash values to reverse common passwords significantly faster than brute-force or dictionary attacks. Each table maps a chain of plaintext → hash → transformation → plaintext → hash sequences, allowing rapid lookup of a target hash by finding its matching position in the chain and working backwards.

Types & Variations

  • Classic Rainbow Table — Precomputed hash chains for a specific hash algorithm (e.g., MD5) and character set; covers millions of common passwords
  • Salted Rainbow Tables — Extended tables that account for known salt values; requires one table per salt value (defeats salt effectiveness)
  • Hash Cracking Alternatives: Dictionary attacks (faster if password is in wordlist), brute force (slower but exhaustive), hybrid attacks (dictionary + character substitution rules)
  • Defensive Countermeasures: Salting (unique random value per password), key stretching (iterated hashing like PBKDF2, bcrypt, scrypt, Argon2), and length requirements

Common Tools & Techniques

rainbowcrack (original tool) hashcat (modern GPU-accelerated alternative) John the Ripper Ophcrack (LM/NTLM specific)

Ethical hackers and security professionals use these tools in authorized penetration tests and red team operations. Unauthorized use is illegal under the Computer Fraud and Abuse Act (CFAA) and equivalent legislation worldwide.

Real-World Examples

MD5 Rainbow Table: 1e87303934c6a1b4d3a1b4c2e5f6... matches "password123" in table — found in <1 second vs hours for brute force
NTLM Hash: LM hash splits "PASSWORD" into "PASSWO" + "RD____" (7+7 chars) — each half cracked independently, halving effective search space
Salt Defeats Table: Stored hash = SHA256(password + "a3f8c2e1") — no precomputed table exists for this specific salt; must brute-force or use dictionary with that salt applied

How Rainbow Table Attack Appears on the CEH v13 Exam

Rainbow tables are covered in CEH v13 Module 06 (System Hacking) in the context of password attacks and credential recovery. The exam tests understanding of how hash chains work, why salting defeats rainbow tables (each salt requires separate table), the difference between LM and NTLM hashing (LM splits password into two 7-char halves, making it weaker), modern password storage best practices (bcrypt/scrypt/Argon2 with high cost factors), and how to identify which hashing algorithm was used from stored hash format. Questions may present hash values for algorithm identification.

Prevention & Detection

  • Input Validation: Implement strict allowlist-based input validation on all user-facing parameters
  • Principle of Least Privilege: Run applications with minimum required permissions
  • Regular Patching: Maintain timely vulnerability management and patch deployment
  • Network Segmentation: Limit lateral movement through zone-based network architecture
  • Monitoring & Alerting: Deploy SIEM/SOAR solutions with threat detection rules for anomalous activity
