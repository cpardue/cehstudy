WPA2 Cracking

WPA2 Cracking refers to the process of recovering the pre-shared key (PSK) or passphrase of a Wi-Fi network protected by WPA2-PSK encryption. The primary method involves capturing the 4-way handshake during client association, then performing offline dictionary or brute-force attacks against the captured handshake data using tools like Aircrack-ng.

Types & Variations

  • 4-Way Handshake Capture — Forces a client reconnection (deauth), captures EAPOL handshake frames containing PMK-derived keys for offline cracking
  • PMKID Attack — Captures the Pairwise Master Key ID from the association response; does not require a connected client to obtain crackable data
  • WPA-Enterprise (802.1X) Attacks — Target PEAP/EAP-TLS authentication: deauth for offline ASLEAP attack, or online dictionary against RADIUS server
  • WPS PIN Attack — Exploits WPA Wi-Fi Protected Setup 8-digit PIN with split authentication vulnerability (4+4 digits), ~11,000 attempts max
  • WPA3 Improvements: SAE (Simultaneous Authentication of Equals) — Eliminates PSK-derived PMK, resistant to offline attacks; still vulnerable to online brute force and evil twin

Common Tools & Techniques

Aircrack-ng (primary) airmon-ng / airodump-ng (monitor mode + capture) hashcat (offline cracking, GPU-accelerated) Reaver (WPS PIN)

Ethical hackers and security professionals use these tools in authorized penetration tests and red team operations. Unauthorized use is illegal under the Computer Fraud and Abuse Act (CFAA) and equivalent legislation worldwide.

Real-World Examples

Classic Deauth+Crack: airodump-ng -c 6 --bdaaa:bb:cc:dd:ee:ff wlan0mon — capture handshake → aircrack-ng -w rockyou.txt capture.cap (GPU-assisted with hashcat)
PMKID: airodump-ng --pmkid pmkid.bin — captures PMKID from association; hashcat -m 16900 pmkid.bin wordlist.txt
WPS Reaver: reaver -i wlan0mon -B -c 6 -vv — brute-forces WPS PIN in split mode, recovers PSK in ~11k attempts max

How WPA2 Cracking Appears on the CEH v13 Exam

WPA2/WPA3 security is CEH v13 Module 16 (Attacking Wireless Networks). The exam tests understanding of the WPA2 4-way handshake process (ANonce, SNonce, PMK, PTK derivation), how deauthentication triggers reconnection and handshake, PMKID capture mechanics, WPS vulnerability specifics, WPA3 SAE improvements and remaining weaknesses, and enterprise wireless security (802.1X, RADIUS). Questions may present handshake captures for analysis or ask about specific attack feasibility given network conditions.

Prevention & Detection

  • Input Validation: Implement strict allowlist-based input validation on all user-facing parameters
  • Principle of Least Privilege: Run applications with minimum required permissions
  • Regular Patching: Maintain timely vulnerability management and patch deployment
  • Network Segmentation: Limit lateral movement through zone-based network architecture
  • Monitoring & Alerting: Deploy SIEM/SOAR solutions with threat detection rules for anomalous activity

Related Glossary Terms

  • Man-in-the-Middle Attack — Deauth is a form of MitM; evil twin extends to full interception
  • Denial of Service — Deauthentication flood is a wireless DoS technique
