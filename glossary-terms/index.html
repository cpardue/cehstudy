CEH v13 Glossary — Key Security Terms

A comprehensive glossary of the most important cybersecurity terms tested on the CEH v13 exam. Each term page includes a definition, types/variants, common tools, real-world examples, prevention strategies, and how the topic appears on the exam.

Attack Techniques

SQL Injection

Code injection into database queries via unsanitized input

Cross-Site Scripting (XSS)

Malicious script injection into web pages viewed by users

Command Injection

OS command execution via unsanitized application parameters

Directory Traversal

Path manipulation to access files outside web root

Phishing Attack

Social engineering via fake communications to steal credentials

Social Engineering

Psychological manipulation to bypass technical security controls

Man-in-the-Middle (MitM)

Intercepting and altering communication between two parties

ARP Spoofing

Layer 2 attack poisoning ARP cache for traffic interception

CSRF

Forcing authenticated users to submit unintended requests

Denial of Service (DoS/DDoS)

Overwhelming systems to make them unavailable to users

Vulnerabilities & Exploitation

Buffer Overflow

Memory corruption by writing beyond allocated buffer boundaries

Privilege Escalation

Gaining higher permissions via exploits or misconfigurations

Zero-Day Vulnerability

Unknown software flaw with no available patch or mitigation

Threats & Malware

Advanced Persistent Threat (APT)

Prolonged targeted attacks for espionage or sabotage

Malware

Software designed to harm, spy on, or compromise systems

Keylogger

Surveillance tool recording keystrokes and user activity

Reconnaissance & Scanning

Port Scanning

Identifying open ports and services on target systems

Network Enumeration

Extracting usernames, shares, and config details from networks

Password & Wireless Attacks

Rainbow Table Attack

Precomputed hash tables for rapid password cracking

WPA2/WPA3 Cracking

Recovering Wi-Fi pre-shared keys via handshake capture
