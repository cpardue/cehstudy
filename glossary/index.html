CEH v13 Cybersecurity Glossary

Key terms and definitions from the CEH v13 curriculum. This glossary covers essential concepts across all 20 modules.

A

APT (Advanced Persistent Threat)
A stealthy, long-term threat actor that gains access to a network and remains undetected for extended periods, typically targeting high-value organizations.
Module 1
Availability (A in CIA triad)
Ensuring that systems and data are accessible to authorized users when needed.
Module 1

C

CIA Triad
Core information security model: Confidentiality, Integrity, Availability. The foundation of all security programs.
Module 1
Confidentiality
Ensuring that information is not disclosed to unauthorized individuals, organizations, or processes.
Module 1

D

DDoS (Distributed Denial of Service)
An attack where multiple compromised systems flood a target with traffic, rendering it unavailable to legitimate users.
Module 10

E

Exploit
Code or technique that takes advantage of a vulnerability to cause unintended behavior on a target system.
Module 1

H

Hack Value
A hacker's evaluation of whether a target is worth pursuing. High hack value examples include credit card data over names.
Module 1
Honeypot
A decoy system designed to attract attackers and study their methods, used as a detection and research tool.
Module 12

I

IDoS (Identity Denial of Service)
An attack that targets user accounts and identity systems rather than infrastructure, attempting to lock out legitimate users.
Module 10
IDS (Intrusion Detection System)
A system that monitors network traffic for suspicious activity and generates alerts when potential threats are detected.
Module 12

N

Nmap
A widely-used open-source network scanning tool for discovering hosts, services, and ports on a network.
Module 3

P

Penetration Testing
Authorized simulated cyberattack on a system to evaluate its security. Types include black box, grey box, and white box.
Module 1
Phishing
A social engineering attack using fraudulent communications (usually email) that appear to come from a reputable source.
Module 9

P

Privilege Escalation
Exploiting a bug or vulnerability to gain elevated access to resources that are normally restricted.
Module 5

S

Sniffing
Capturing and analyzing network traffic flowing across a network segment, often used to intercept unencrypted data.
Module 8

S

SQL Injection (SQLi)
An attack that inserts malicious SQL statements into entry fields for execution, potentially accessing or modifying database contents.
Module 15

V

Vulnerability
A weakness in a system that can be exploited by a threat actor to perform unauthorized actions.
Module 1

X

XSS (Cross-Site Scripting)
An attack that injects malicious scripts into otherwise benign websites, executed in the victim's browser.
Module 14

Z

Zero-Day Attack
An exploit that targets a previously unknown vulnerability before the vendor has released a patch.
Module 1
