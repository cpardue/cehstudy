CEH v13 Cybersecurity Glossary

100 terms

Key terms and definitions from the CEH v13 curriculum covering all 20 exam modules. Use this glossary to reinforce vocabulary before your exam.

A

APT (Advanced Persistent Threat)
A stealthy, long-term threat actor that gains access to a network and remains undetected for extended periods, typically targeting high-value organizations with state-sponsored or criminal intent.
Module 1 · Dedicated page →
AES (Advanced Encryption Standard)
A symmetric block cipher operating on 128-bit blocks with key sizes of 128, 192, or 256 bits. The US government standard for encrypting unclassified data and the basis for WPA2 wireless encryption.
Module 20
Aircrack-ng
A suite of tools for assessing Wi-Fi network security, primarily used to capture IVs and crack WEP/TKIP keys, or perform offline attacks on captured handshakes.
Module 16
Asymmetric Encryption
A cryptographic system using a mathematically related public/private key pair. Data encrypted with one key can only be decrypted with the other. Used for key exchange, digital signatures, and authentication.
Module 20
Availability (A in CIA triad)
Ensuring that systems and data remain accessible to authorized users when needed, protected against denial-of-service attacks and hardware failures.
Module 1

B

Backdoor
A hidden method of bypassing normal authentication to gain unauthorized access to a system, often installed by malware or left behind by attackers for persistent access.
Module 6
Banner Grabbing
Collecting service version information from network services (web servers, FTP, SMTP) to identify potential vulnerabilities associated with specific versions.
Module 3
Baiting
A social engineering attack that lures victims with a seemingly beneficial offer (free USB drive, prize notification) to trigger malware installation or information disclosure.
Module 9
Blind SQL Injection
A SQLi technique where the attacker cannot view query results directly but infers data through boolean responses (true/false) or time-based delays from the application.
Module 15
Botnet
A network of compromised devices (bots) controlled remotely by a command-and-control server, used for DDoS attacks, spam distribution, and data theft.
Module 7 & 10
Brute-Force Attack
A password cracking method that systematically tries every possible character combination until the correct one is found. Effective against short or simple passwords but slow on strong ones.
Module 6
Buffer Overflow
A memory corruption vulnerability where more data is written to a buffer than it can hold, overwriting adjacent memory and potentially allowing arbitrary code execution.
Module 6 · Dedicated page →

C

Certificate Pinning
A mobile security technique that locks an app to a specific certificate or public key, preventing MITM attacks even if the device's trusted CA store is compromised.
Module 20
CIA Triad
The foundational information security model: Confidentiality (data not disclosed), Integrity (data not tampered with), Availability (data accessible when needed).
Module 1
Clickjacking
An attack that uses transparent or invisible HTML overlays to trick users into clicking on something different from what they perceive, enabling unauthorized actions within a session.
Module 14
Command Injection
An attack where user input is passed to a system shell, allowing the attacker to execute arbitrary OS commands by inserting command separators like semicolons or pipes.
Module 13 · Dedicated page →
Confidentiality
Ensuring that information is not disclosed to unauthorized individuals, organizations, or processes. Achieved through encryption, access controls, and classification.
Module 1
Container Escape
An attack that breaks out of a containerized environment (Docker, Kubernetes) to access the underlying host system, potentially compromising other containers on the same host.
Module 19
Credential Stuffing
Automated attack using username/password pairs harvested from one breach to attempt login on other services, exploiting user password reuse.
Module 6
Cross-Site Request Forgery (CSRF)
An attack that forces an authenticated user's browser to execute unintended actions on a trusted site by forging requests that appear legitimate due to active sessions.
Module 14 · Dedicated page →
Cryptographic Hash Function
A one-way function producing a fixed-size digest from arbitrary input data (e.g., SHA-256, MD5). Used for data integrity verification, password storage, and digital signatures.
Module 20
CVSS (Common Vulnerability Scoring System)
A standardized framework for rating vulnerability severity on a scale of 0-10, based on exploitability metrics (attack vector, complexity, privileges) and impact metrics (confidentiality, integrity, availability).
Module 5
CVE (Common Vulnerabilities and Exposures)
A unique identifier assigned to publicly disclosed information security vulnerabilities, enabling consistent referencing across tools, databases, and advisories.
Module 5

D

Deauthentication Attack
A wireless attack sending forged deauth frames to disconnect clients from a legitimate AP, forcing reconnection to a rogue AP or enabling handshake capture for offline cracking.
Module 16
Denial of Service (DoS)
An attack that overwhelms a target system with traffic or resource exhaustion, making it unavailable to legitimate users. Can target network bandwidth, CPU, memory, or application logic.
Module 10 · Dedicated page →
DDoS (Distributed Denial of Service)
A DoS attack coordinated from multiple compromised systems (botnet) to amplify traffic volume beyond what a single-source attack can achieve.
Module 10
Dictionary Attack
A password cracking method using a pre-compiled word list to guess passwords, significantly faster than brute-force for dictionary-based passwords.
Module 6
Directory Traversal
An attack using path manipulation sequences (../) to access files and directories outside the intended web root, potentially reading sensitive system files.
Module 13 · Dedicated page →
DNS Enumeration
Discovering information about a target's DNS infrastructure including subdomains, mail servers, and name servers through queries, zone transfers, and brute-forcing.
Module 2
DNS Zone Transfer (AXFR)
A DNS protocol mechanism (type 256) that copies an entire zone file from primary to secondary servers. If misconfigured, attackers can harvest all subdomains and internal hostnames.
Module 2
Dumpster Diving
Searching through discarded materials (paper documents, storage media) to find sensitive information such as credentials, network diagrams, or business plans.
Module 9

E

Evil Twin Attack
Deploying a rogue wireless access point with the same SSID as a legitimate network to intercept traffic and harvest credentials through man-in-the-middle position.
Module 16
Exploit
Code or technique that takes advantage of a vulnerability to cause unintended behavior on a target system, such as gaining unauthorized access or causing a crash.
Module 1
Exploit Kit
A commercial tool used by criminals to exploit web browser and plugin vulnerabilities, often deployed via malvertising or compromised websites to deliver payloads without user interaction.
Module 5 & 14

F

Fileless Malware
Malware that operates entirely in RAM using living-off-the-land binaries (PowerShell, WMI) without writing executables to disk, evading traditional antivirus detection.
Module 7
Firmware Extraction
Reading the embedded software (firmware) from IoT/OT devices for offline analysis to discover hardcoded credentials, backdoors, and undocumented attack surfaces.
Module 18
Frag Attack
A DoS technique sending malformed IP fragments with overlapping offsets, crashing systems that fail to handle the inconsistency properly.
Module 10 & 12

G

Grey Hat Hacker
An ethically ambiguous actor who may violate policies or laws but without malicious intent, often exposing vulnerabilities to raise awareness rather than sell exploits.
Module 1

H

Hack Value
A hacker's assessment of whether a target is worth pursuing based on the value of accessible data. High hack value includes financial data; low includes publicly available information.
Module 1
Hacktivist
A threat actor who conducts cyberattacks for political, social, or ideological causes, targeting organizations to draw attention to their agenda.
Module 1
Hash Function
A mathematical function that converts variable-length input into a fixed-length output (digest). Properties include determinism, pre-image resistance, and avalanche effect.
Module 20
Honeypot
A decoy system designed to attract and engage attackers, providing intelligence on their methods while isolating them from production systems. Types include production, research, and honeytokens.
Module 12
Hybrid Attack
A password cracking technique combining dictionary words with numeric suffixes or leet-speak substitutions (e.g., "password1", "p@ssw0rd") to crack modified passwords efficiently.
Module 6

I

IDoS (Identity Denial of Service)
An attack targeting user accounts and identity systems (password resets, MFA) rather than infrastructure, locking legitimate users out of their own accounts.
Module 10
IDS (Intrusion Detection System)
A monitoring system that analyzes network traffic or system activity for policy violations and generates alerts. Types: signature-based, anomaly-based, NIDS, HIDS.
Module 12
Integrity (I in CIA triad)
Ensuring that information remains accurate, complete, and unaltered by unauthorized parties. Verified through checksums, digital signatures, and access controls.
Module 1
IPS (Intrusion Prevention System)
A security system that actively monitors traffic and blocks identified threats in real-time, unlike IDS which only alerts. Can drop packets, block IPs, or terminate sessions.
Module 12

J

Jailbreaking / Rooting
Removing manufacturer-imposed software restrictions on iOS (jailbreak) or Android (root) devices, enabling installation of unauthorized apps and access to system-level functionality. Expands the attack surface for security testing.
Module 17

K

Key Exchange Protocol
Cryptographic methods (Diffie-Hellman, ECDH) that allow two parties to establish a shared secret over an insecure channel without prior shared information, enabling subsequent symmetric encryption.
Module 20
Keylogger
Malware or hardware device that records keystrokes to capture passwords, credit card numbers, and other sensitive input. Can be software-based, hardware-based, or API-hooking.
Module 6 · Dedicated page →

L

LDAP Enumeration
Querying Lightweight Directory Access Protocol servers to extract user accounts, group memberships, and organizational structure information from directory services.
Module 4
Logic Bomb
Malicious code embedded in a legitimate program that executes destructive actions when specific conditions are met (date, variable value, user action).
Module 7

M

Malware
Malicious software designed to damage, disrupt, or gain unauthorized access to computer systems. Includes viruses, worms, trojans, ransomware, spyware, and rootkits.
Module 7 · Dedicated page →
Man-in-the-Middle (MITM)
An attack where an adversary intercepts and potentially alters communication between two parties who believe they are directly communicating. Enabled by ARP spoofing, rogue APs, or DNS poisoning.
Module 8 · Dedicated page →
MAC Flooding
Overwhelming a switch's MAC address table with forged source addresses, forcing it into fail-open mode (hub behavior) and enabling network sniffing on switched networks.
Module 8

N

Nessus
A commercial vulnerability scanner that identifies security weaknesses in networks, web applications, and operating systems using a large plugin database of known vulnerabilities.
Module 5
NetBIOS Enumeration
Using the NetBIOS protocol (UDP 137/138, TCP 139) to enumerate computer names, user accounts, and shared resources on Windows networks.
Module 4
Nmap
The de facto standard open-source network scanning tool for host discovery, port scanning, service version detection, and OS fingerprinting. Supports multiple scan types and scriptable NSE engine.
Module 3

O

Open Redirect
A web vulnerability where an application redirects users to a URL derived from user input without proper validation, enabling phishing attacks that appear to originate from the trusted domain.
Module 14
OWASP Top 10
A regularly updated standard awareness document listing the ten most critical security risks to web applications: injection, broken authentication, sensitive data exposure, XXE, broken access control, misconfiguration, XSS, insecure deserialization, vulnerable components, insufficient logging.
Module 14

P

Packet Sniffer / Wireshark
A tool that captures and analyzes network traffic at the packet level. Wireshark is the leading open-source sniffer used for protocol analysis, troubleshooting, and security monitoring.
Module 8
Pass the Hash
An attack that uses a captured password hash (NTLM) directly for authentication instead of cracking it to plaintext, leveraging Windows' ability to authenticate via hash comparison.
Module 6
Patch Management
The systematic process of identifying, testing, deploying, and verifying security patches across an organization's systems to close known vulnerabilities within defined timeframes.
Module 5
Penetration Testing
Authorized simulated cyberattack evaluating system security through reconnaissance, scanning, exploitation, post-exploitation, and reporting. Types: black box, grey box, white box.
Module 1
Phishing
A social engineering attack using fraudulent communications (usually email) appearing to come from reputable sources to trick victims into revealing sensitive information or executing malicious actions.
Module 9 · Dedicated page →
Ping Sweep
A network discovery technique sending ICMP echo requests (or TCP/UDP probes) to a range of IP addresses to identify which hosts are online before detailed scanning.
Module 3
Polymorphic Malware
Malware that rewrites its own code with each infection using a mutation engine, producing a different signature each time while maintaining the same functionality. Evades signature-based detection.
Module 7
Port Scanning
Probing a target system's network ports to identify open services and potential entry points. Types include SYN, FIN, Xmas, NULL, UDP, and IDLE scans.
Module 3 · Dedicated page →
Pretexting
A social engineering technique where the attacker creates a fabricated scenario (pretext) to manipulate victims into providing confidential information or performing specific actions.
Module 9
Privilege Escalation
Exploiting vulnerabilities, misconfigurations, or design flaws to gain higher access levels. Vertical escalation (user to admin/root); horizontal escalation (user to same-level different user).
Module 6 · Dedicated page →
PTW (Pytho's Tiny WepAttack) / Frag-N-Inject
A practical attack against TKIP (WPA) that exploits a flaw in the key mixing function, allowing an attacker to forge packets by predicting the TKIP key stream.
Module 16
Public Key Infrastructure (PKI)
A framework of hardware, software, policies, and processes for creating, distributing, managing, and revoking digital certificates. Components: CAs, RA, certificate repositories, and certificate status lists.
Module 20

R

Ransomware
Malware that encrypts victim's files or locks the system, demanding payment (usually cryptocurrency) for decryption. Variants include crypto ransomware, locker ransomware, and doxxing malware.
Module 7
Rainbow Table Attack
Using precomputed chains of hash values to quickly reverse cryptographic hashes into plaintext passwords. Defeated by adding per-password random salt values before hashing.
Module 6 · Dedicated page →
Reconnaissance
The initial phase of a hacking engagement gathering information about the target. Passive (OSINT, social media, WHOIS) leaves no trace; Active (scanning, probing) generates network traffic.
Module 2
Rogue Access Point
An unauthorized wireless access point connected to an organization's network, creating an unmonitored entry point for attackers. May be intentional (employee) or malicious.
Module 16
Rootkit
Malware that installs itself deep within an operating system to hide its presence from security tools, providing attackers with persistent privileged access. Types: user-mode, kernel-mode, firmware, hypervisor.
Module 7
RSA (Rivest-Shamir-Adleman)
The most widely used asymmetric encryption algorithm, based on the mathematical difficulty of factoring large prime numbers. Used for key exchange and digital signatures with 2048+ bit keys.
Module 20
RST Injection
Sending a TCP Reset packet with a spoofed source IP to force termination of an active connection, severing the victim's session before the attacker injects its own packets.
Module 11

S

SAE (Simultaneous Authentication of Equals)
WPA3's Dragonfly-based key exchange providing forward secrecy and resistance to offline dictionary attacks by never exposing values usable for offline guessing.
Module 16
SCADA (Supervisory Control and Data Acquisition)
Industrial control system architecture used to monitor and control physical processes in infrastructure (power grids, water treatment). SCADA systems are high-value targets for APT actors.
Module 18
Script Kiddie
An inexperienced attacker who uses pre-made exploit tools, scripts, or automated attack tools without understanding the underlying concepts, often causing more disruption than damage.
Module 1
Session Fixation
An attack where the attacker plants a known session identifier for the victim (via URL, cookie injection) before authentication, then uses that ID to hijack the authenticated session.
Module 11
Shellshock (CVE-2014-6271)
A critical GNU Bash vulnerability allowing remote code execution via environment variable injection. Affected CGI scripts, DHCP clients, and embedded systems running Bash.
Module 13
Shadow IT
Technology systems and services used by employees without explicit IT department approval, creating unmonitored data stores and attack surfaces outside security policy.
Module 19
SMB Enumeration
Querying Server Message Block protocol (TCP 445/139) to enumerate user accounts, groups, shares, and system information on Windows networks.
Module 4
Slowloris
An application-layer DoS attack that opens many HTTP connections and sends partial headers slowly, exhausting the web server's connection pool without consuming significant bandwidth.
Module 10
SNMP Enumeration
Querying Simple Network Management Protocol (UDP 161/162) using community strings (often default "public") to extract network device configuration, topology, and system information.
Module 4
Social Engineering
Manipulating people to violate security procedures or reveal confidential information. The human element is often the weakest link in any security architecture.
Module 9 · Dedicated page →
Spear Phishing
A targeted phishing attack aimed at a specific individual or organization, using researched personal/organizational details to make the message appear legitimate and credible.
Module 9
SQL Injection (SQLi)
An attack inserting malicious SQL code into input fields to manipulate database queries, enabling data theft, modification, authentication bypass, or server compromise.
Module 15 · Dedicated page →
SSL Stripping
A MITM attack downgrading HTTPS connections to HTTP by exploiting the transition period before an application redirects to the secure version, capturing unencrypted traffic.
Module 8
State-Sponsored Threat Actor
A government-backed adversary conducting sophisticated cyber operations for intelligence gathering, strategic disruption, or economic espionage. Resources and sophistication far exceed criminal groups.
Module 1
Steganography
Hiding data within other data (images, audio, video) to conceal the existence of communication. Used both offensively for covert channels and defensively for detecting hidden content.
Module 9
SYN Flood
A DoS attack sending large volumes of SYN packets with spoofed source IPs, exhausting the target's connection backlog table and preventing new legitimate connections.
Module 10
SYN Scan (Half-Open Scan)
A port scanning technique sending SYN packets and observing the response (SYN/ACK = open, RST = closed) without completing the three-way handshake, reducing detectability.
Module 3
Sidejacking (Session Hijacking)
Stealing a user's active session cookie from unencrypted HTTP traffic using a network sniffer, then using it to impersonate the victim without knowing their password.
Module 11

T

Tailgating (Piggybacking)
Physical social engineering technique where an unauthorized person follows an authorized individual through a security checkpoint without independently authenticating.
Module 9 & 20
TCP Sequence Number Prediction
Observing the increment pattern of TCP SEQ/ACK values to predict the next expected sequence number, enabling an attacker to craft packets that appear legitimate within the session.
Module 11
Teardrop Attack
A legacy DoS attack sending malformed IP fragments with overlapping offsets that crash older operating systems failing to properly reassemble the fragments.
Module 10
Trojan Horse
Malicious software disguised as legitimate or useful software. Unlike viruses, trojans do not self-replicate but provide backdoors, data theft, or other malicious functionality.
Module 7

U

Union-Based SQL Injection
A SQLi technique using UNION SELECT statements to combine attacker-controlled queries with the application's original query, directly extracting data from other tables in the database.
Module 15

V

Vishing (Voice Phishing)
A social engineering attack using telephone calls to trick victims into revealing sensitive information, often impersonating IT support, banks, or government agencies with urgency tactics.
Module 9
Vulnerability
A weakness in system design, implementation, or operation that can be exploited by a threat actor to perform unauthorized actions, violate security policies, or compromise assets.
Module 1 & 5
Vulnerability Scanning
Automated scanning of systems and networks to identify known security weaknesses by matching against databases of vulnerability signatures. Tools: Nessus, OpenVAS, Qualys.
Module 5

W

WEP (Wired Equivalent Privacy)
The original Wi-Fi security protocol using RC4 with a 24-bit initialization vector. Fundamentally broken due to IV reuse; crackable in minutes under moderate traffic conditions.
Module 16
WPA2 / WPA3
Wi-Fi security protocols. WPA2 uses AES-CCMP (PMKID, 4-way handshake) and remains the most deployed standard. WPA3 introduces SAE for forward secrecy and enhanced enterprise protections.
Module 16 · Dedicated page →
Whaling
A targeted phishing attack aimed at high-level executives (C-suite), using highly personalized lures to exploit their authority and access to sensitive organizational data.
Module 9
WHOIS Lookup
Querying the WHOIS database to retrieve domain registration information including registrant, admin contact, creation/expiry dates, and name servers. A foundational passive reconnaissance technique.
Module 2
White Hat Hacker
An ethical security professional who tests systems and networks with explicit authorization to identify vulnerabilities and help organizations strengthen their defenses.
Module 1
Window of Vulnerability (WOV)
The time period from when a vulnerability is discovered or disclosed until the majority of affected systems are patched. Critical for prioritizing incident response and patch deployment.
Module 1
Worm
A self-replicating malware that spreads across networks without user interaction, exploiting vulnerabilities to propagate. Can consume bandwidth and cause system instability at scale.
Module 7

X

XSS (Cross-Site Scripting)
An attack injecting malicious client-side scripts into web pages viewed by other users. Types: reflected, stored (persistent), and DOM-based. Enables session theft and account takeover.
Module 14 · Dedicated page →
Xmas Tree Scan
A stealth port scan sending packets with all TCP flags set (FIN, URG, PSH, RST, SYN, ACK). Open ports respond with RST; filtered ports show no response. Difficult to log with simple IDS.
Module 3
XXE (XML External Entity)
A web attack exploiting XML parsers that process external entity declarations, enabling file read, SSRF, and data exfiltration through crafted XML input.
Module 14

Z

Zero-Day Attack / Vulnerability
An exploit targeting a previously unknown vulnerability before the vendor has released a patch. Zero-days are the most dangerous because no defensive signature exists and detection relies on anomaly-based methods.
