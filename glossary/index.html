CEH Cybersecurity Glossary

Key terms and definitions for CEH exam preparation.

CIA Triad
Confidentiality, Integrity, Availability — the three foundational pillars of information security.
SQL Injection
An attack that injects malicious SQL code into an application's query to manipulate or extract database information.
XSS (Cross-Site Scripting)
An attack that injects malicious scripts into web pages viewed by other users.
Firewall
A network security system that monitors and controls incoming and outgoing traffic based on predetermined rules.
Phishing
A social engineering attack where attackers trick users into revealing sensitive information via fraudulent communications.
Malware
Malicious software designed to harm computers, servers, or networks including viruses, worms, trojans, and ransomware.
Denial of Service (DoS)
An attack that overwhelms a system with traffic to make it unavailable to legitimate users.
Man-in-the-Middle (MitM)
An attack where the attacker secretly intercepts and relays communications between two parties.
Social Engineering
Psychological manipulation of people to perform actions or divulge confidential information.
Zero-Day Vulnerability
A security flaw unknown to the vendor that can be exploited by attackers before a patch is available.
