Module 16: Mobile Platforms

Section 1: Mobile Device Architecture

Mobile platforms consist of hardware (processor, memory, sensors) and software (OS, applications).

Mobile Operating Systems

  • Android: Open-source OS by Google, based on Linux kernel. Supports sideloading APKs.
  • iOS: Apple's proprietary OS for iPhone. Closed ecosystem with App Store review process.

Section 2: Mobile Security Features

iOS Security: Secure Enclave, App Sandbox, Code Signing, Gatekeeper, Data Protection

Android Security: Linux Kernel with SELinux, Application Sandbox, Google Play Protect, Verified Boot, Runtime Permissions

Section 3: Mobile Malware

Types: Trojan Horses (most common), Ransomware, Rootkits, Spyware, Worms, Bots/Botnets

Mobile-Specific Examples: TeslaCrypt (Android ransomware), Cerberus (banking trojan), Pegasus (iOS spyware by NSO Group), FinFisher

Section 4: Mobile Attack Vectors

Network Attacks: Eavesdropping, MITM (IMSI catchers/Stingrays), Bluetooth (Bluesnarfing, Bluejacking), Wi-Fi (Evil twin APs), NFC Skimming

Application Attacks: Malicious Apps (sideloading), Supply Chain Attacks, Reverse Engineering, Insecure Data Storage

Physical Attacks: Device Theft, Chargen Attack, Jailbreak/Root Detection Bypass

Section 5: Mobile Device Management (MDM)

MDM Solutions: VMware Workspace ONE, Microsoft Intune, Citrix XenMobile

MDM Capabilities: Remote provisioning, Policy enforcement, Containerization, Remote wipe, Compliance monitoring

Section 6: BYOD (Bring Your Own Device)

BYOD Challenges: Data Mixing, Privacy Concerns, Device Diversity, Jailbreak/Root

BYOD Controls: MAM (Mobile Application Management), MIM (Mobile Information Management), VPN, Acceptable Use Policy

Section 7: Mobile Security Best Practices

  • Keep OS and apps updated with latest security patches
  • Enable device encryption and strong authentication
  • Use MDM solutions for corporate devices
  • Implement containerization for work data separation
  • Install apps only from official stores
  • Review app permissions before installation
  • Enable remote tracking and wiping capabilities
  • Use VPN on public Wi-Fi networks
  • Disable Bluetooth/NFC when not in use
  • Implement multi-factor authentication for corporate access

Section 8: Notable Mobile Security Incidents

Pegasus Spyware (2016-present)

NSO Group spyware exploits zero-day vulnerabilities in iOS and Android. Reads messages, accesses camera/microphone, tracks location.
